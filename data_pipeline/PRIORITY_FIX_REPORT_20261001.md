# 실시간 수집 우선순위 수정 — 2026-10-01

대상은 과거 운영 프로젝트 `/home/dheorb/workspace/projects/school/Earning-Whisperer`이다. 이번 변경의 목적은 MU/JBL의 종료 미인식, 지난 콜 재수집, 과거 세션 때문에 막히는 일정 갱신, 출처 간 시각 충돌을 공통 로직에서 처리하는 것이다.

## 수정한 동작

1. **실제 종료 안내 처리.** MU의 “Q&A session and today's call”과 disconnect 조합, JBL의 종료 후 인사·연결 해제 안내를 인식한다. Q&A 종료만으로 콜 전체를 끝내지 않는다. 실제 발화가 재개되면 종료 후보를 취소한다. 반복 문장을 저장할 때 중복 제거하더라도 종료 판정에는 원본 STT를 사용한다. 종료 이후 처리된 무발화 60초, 두 구간 이상, 처리 지연·같은 세션/행사 증명, 마지막 PCM 처리는 유지한다.
2. **과거 콜 재시작 방지.** 수집 이력이 있는 콜의 새 시도는 정확한 시작 시각 + 180분 이내로 제한한다. 시각이 불명확하면 미국 동부 행사 당일과 자정 이후 180분까지만 허용한다. 설정은 기존 `DATE_STREAM_NEAR_END_MINUTES`이다. 후보 조회·DB 작업 선점·녹음 승격에 동일한 조건을 둔다. 시간 증거가 오래됐다는 이유로 지난 일정이 무제한 날짜 감시로 되돌아가지 않는다. 처음 탐색하는 콜과 정식으로 변경된 일정의 새 revision은 구분한다. **이미 실행 중인 정상 녹음은 이 제한으로 중단하지 않는다.**
3. **장시간 무발화 재시도 제한.** 발화를 들은 뒤 `live_speech_idle_timeout`이 반복되면 전체 capture 시도 수 기본 3회에서 실패/점검 상태로 멈춘다. `DATE_STREAM_IDLE_CAPTURE_MAX_ATTEMPTS`로 조정한다. 종료 성공으로 처리하지 않는다. 방송 시작 전 대기·폼 탐색 횟수 제한과는 별개다.
4. **검증된 녹화본의 재선택 방지.** 같은 행사·현재 페이지·현재 플레이어가 명확한 ended/replay 기록과 연결된 경우에만 녹음 승격을 거절한다. 이때 이전 후보 캐시를 폐기하고 같은 일정 revision의 다른 경로를 재탐색한다. 대기 음악·페이지의 다른 과거 링크·불명확한 소스·고정 파일 하나만으로 거절하지 않는다. 승격 직전 다시 검사한다. 진단에서 가린 서명 URL은 원래 URL 해시가 일치할 때만 복구하여 비교한다.
5. **재생 소스 관측 개선.** Q4 `/attendee/<id>`와 `/guest`를 같은 행사로 연결한다. 실제 플레이어의 미디어 주소 해시와 관측한 HLS 정보를 비교한다. 신선한 실제 생방송 전송, 단일 활성 오디오 플레이어, 현재 세션 음성·STT·DB 저장·아카이브 기록을 따로 확인한다. 다른 활성 플레이어가 있으면 오디오 출처를 검증 완료로 표시하지 않는다. MSE/blob와 네트워크 스트림이 연결되지 않으면 미검증 상태를 유지한다.
6. **종료된 세션 이후의 정규 일정 갱신.** 과거 `capture_session_id`는 기록으로 남겨도 현재 수집·탐색·유효 lease가 없으면 공식 시각 갱신이 가능하다. 진행 중인 작업·revision 경쟁·취소·일정 변경 보호는 유지한다.
7. **회사 페이지와 제공자 페이지의 시각 비교.** 회사 시각을 찾았더라도 같은 행사에 연결된 provider 시각을 제한된 요청·브라우저 예산으로 확인한다. 충돌은 양쪽 URL, 원문, 시간대, UTC와 함께 DB에 남긴다. 한쪽 장애만으로 충돌을 해제하지 않는다. issuer 장애 시 과거에 인증한 provider는 기존 시각의 모순을 확인하는 데만 사용한다. 이것만으로 정확한 시각을 확정하거나 기존 주소 증명의 유효기간을 연장하지 않는다. 시각만 충돌하고 행사 주소 증명이 남아 있으면 `provisional_watch`로 감시는 계속한다.
8. **정리 프로세스 회수.** 브라우저·오디오 정리 후 멈춘 finalizer를 5초 내 중단하는 기존 정책에 `timeout --foreground`를 추가했다. timeout 자체가 함께 죽어 finalizer zombie를 남기던 현상을 방지한다. 원본 PCM 보존과 다른 수집 세션 보호를 유지한다.

## 운영 확인 지점

- `capture_retry_window_expired`: 지난 콜 재시작 차단. 원래 콜을 성공/완료로 위장하지 않는다.
- `speech_idle_retry_limit`: 실제 발화 이후 긴 무발화 반복으로 자동 재시도 중단.
- `VERIFIED_REPLAY_SOURCE` / `replay_admission_rejected`: 녹화본 확정 및 다른 후보 재탐색.
- `capture_source`: 행사 일치, 실제 미디어 해시, 생방송 전송 증명과 검증되지 않은 이유.
- `schedule_enrichment`: 읽은 페이지·브라우저 예산·실패 출처·시각 충돌과 경로 재사용 판단.
- `operator_closing_candidate` / `CAPTURE_CLEANUP_DONE`: 종료 후보의 유지·취소, 수집 자원 정리 완료.
