# 공통 행사 식별·시각·일정 갱신 개선 — 2026-09-29

## 구현

1. **행사 링크와 목록 이동 구분**
   - `Past Events`, `Today`, 행사 목록 보기 같은 내비게이션은 주변의 어닝콜 제목·날짜를 물려받아 재생 후보가 될 수 없다.
   - 시간 보강의 DOM 후보와 생방송 브라우저의 후보 순위, 저장된 학습 규칙, 실제 클릭 직전 재확인, 기존 잘못된 접속 증명에 동일한 구분을 적용한다.
   - 상세 페이지에서 웹캐스트를 확보하면 상위 목록의 빈 경로로 덮어쓰지 않는다. `Earnings Call`이라고 표시된 같은 출처 상세 링크도 한 단계 따라간다.
   - 서로 다른 날짜·회계기간의 시간과 접속 주소를 하나의 행사 증명으로 합치지 않는다. 상위 카드에서 얻은 행사 식별 정보를 상세 페이지 검증까지 전달한다.

2. **행사별 시각·취소 상태 추출**
   - 목표 회계기간을 각 행사 영역에서 대조한 뒤 시간을 모은다. Investor Day·Capital Markets Day·별도 실적 후 애널리스트 콜 등은 어닝콜의 시각으로 사용하지 않는다.
   - HTML, 직렬화된 브라우저 관측, JSON-LD, 캘린더 자료에서 행사 제목을 함께 유지한다. 넓은 본문은 문장별 분기를 다시 확인한다.
   - 다른 행사에 날짜 이동 허용 권한이 전파되지 않는다. 다른 분기의 취소·미정 상태가 목표 어닝콜을 취소시키지 않는다.
   - 같은 행사의 실제 시각 상충, 시작시간 미정, 실적 공개 시각과 콜 시작시각 구분, 시간대 검증은 유지한다.

3. **일정 통합과 검색 없는 재탐색**
   - 불완전하거나 오래된 `event-details` 경로는 같은 출처의 상위 행사 목록으로 제한된 횟수만큼 복귀한다. 이동 자체는 행사 증명으로 인정하지 않는다.
   - 공식 회계연도·분기 확인과 최근 48시간 이내의 명시적 Nasdaq 날짜 수정 근거가 함께 있으면, 최대 14일 차이의 유일한 미확정 중복 행을 `superseded`로 정리한다. 분기 경계 때문에 두 행이 생긴 경우도 처리한다.
   - 날짜나 종목이 가깝다는 이유만으로 합치지 않는다. 진행 중 작업, lease, 전사·캡처·완료 이력, 다른 공식 행사 근거, 더 최신의 관측과 revision은 보존한다. 원 행과 판단 근거는 변경 이력에 남긴다.
   - 시간 보강 브라우저와 감시 브라우저 모두 HTTP 접근 거절을 별도로 기록한다. 403 응답을 정상 페이지 또는 시간 미공개로 오인하지 않는다.
