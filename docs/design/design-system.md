# 디자인 시스템

Logothea 앱 화면의 시각 기준을 정리한 문서입니다. 재질, 색, 글자, 형태, 움직임, 컴포넌트 사용 규칙, 상태 패턴,
문구 규칙을 다루며 화면을 만들거나 고치는 기여자를 위한 문서입니다. 화면 구조와 흐름은 [UX 문서](ux.md)에서,
이름 · 말투 · 로고는 [브랜드 문서](brand.md)에서 다룹니다.

토큰 값의 기준은 코드의 토큰 파일(`trading-terminal/src/renderer/styles/tokens.css`)입니다. 이 문서는 쓰는 규칙과
이유를 남깁니다. 재질은 같은 폴더의 `global.css` 에 `glass` · `rim` · `frost` · `gbtn` 클래스로 있습니다.

## 컨셉

Apple 리퀴드 글래스를 바탕으로 합니다. 맑은 유리 위에 얇은 금테를 두르는 것이 Logothea 의 고유한 재질입니다.
금테는 비잔틴 유리 모자이크의 금박에서 가져왔고, 버튼에 쓰는 라피스 · 올리브 · 포르피라는 그리스 · 비잔틴을 떠올리게
하는 색입니다.

| 원칙 | 내용 | 이유 |
|---|---|---|
| 유리는 조작층에 | 메뉴, 콜 바, 버튼, 세그먼트, 주문 시트, 팝오버가 유리입니다 | Apple 규칙과 같습니다. 조작 요소가 내용 위에 떠 있음을 보여 줍니다 |
| 읽을거리는 서리 유리에 | 자막, 종합 판단 본문은 짙은 서리 유리 면에 둡니다 | 비치는 재질을 유지하면서 긴 글을 읽을 수 있어야 합니다 |
| 색상 유리는 버튼에만 | 라피스 · 올리브 · 포르피라 유리는 버튼에만 씁니다 | 색이 있는 면은 누를 수 있는 것이라는 뜻을 지킵니다 |
| 색상 유리 주 버튼은 화면에 하나 | 한 화면에서 가장 중요한 행동 하나만 색상 유리로 둡니다 | 다음에 할 일을 하나로 좁힙니다 |
| 바탕은 단색 | 바탕에 그림이나 그라데이션를 두지 않습니다 | 화면이 차분해야 하고 유리가 내용을 가리지 않아야 합니다 |
| 다크 전용 | 지금은 다크 테마만 정의합니다. 토큰은 라이트를 더할 수 있게 나눠 둡니다 | 콜이 밤에 열리고, 유리는 어두운 바탕에서 가장 잘 읽힙니다 |

## 재질

### 맑은 유리

모든 유리 부품의 기본입니다. 틴트는 거의 없고, 굴절 · 약한 블러 · 반사광으로 유리를 만듭니다.

| 층 | 값 |
|---|---|
| 몸체 | 위에서 아래로 흰색 10% → 3% 그라데이션 |
| 배경 처리 | 굴절 맵 + `blur(1.5px) saturate(1.6) brightness(1.06)` |
| 윗면 반사선 | 안쪽 위 1px, 흰색 65% |
| 가장자리 | 안쪽 아래 1px 흰색 18%, 왼쪽 1px 22%, 오른쪽 1px 8% |
| 안쪽 빛 | 안쪽 22px, 흰색 6% |
| 반사광 | 왼쪽 위(22%, 0%)에서 퍼지는 흰색 26%, `screen` 합성 |
| 그림자 | 아래 14px, 흐림 34px, 검정 55% |

광원은 왼쪽 위에 하나만 둡니다. 모든 유리의 반사광과 가장자리 밝기는 이 광원을 따릅니다.

**굴절**: 부품마다 크기와 모서리 반경에 맞춘 굴절 맵을 만들어 가장자리에서 뒤를 휘게 합니다. 가장자리 폭은 부품
크기에 따라 판 24px 안팎, 버튼 14px, 작은 칩 10px 입니다. SVG `feDisplacementMap` 을 `backdrop-filter` 에 거는
방식이며 Electron(Chromium)을 대상으로 합니다.

굴절은 기본으로 켭니다. #154 에서 움직이는 글 위에 판 · 캡슐 · 버튼 10개를 겹쳐 재 보았을 때 굴절을 켠 경우와 끈
경우의 프레임 시간이 같았습니다(120Hz 화면에서 평균 8.3ms, Chrome 154). 굴절 맵은 사이드바 크기 기준 한 번에 약
2.4ms 가 걸려 크기가 바뀔 때만 다시 만듭니다. 앱이 쓰는 Electron 31(Chromium 126)에서는 아직 재지 못했습니다.
느린 기기를 위해 끌 수 있게 두었고, 투명도 줄이기 설정이 켜져 있으면 끕니다.

굴절은 내용 위에 떠 있는 유리(콜 바, 주문 시트, 팝오버)에만 겁니다. 메뉴 판처럼 뒤가 단색 바탕인 유리는 휠 것이
없고, 다른 유리 안에 든 유리(고른 메뉴, 세그먼트 썸)는 바깥 유리에 가려 뒤를 보지 못해 굴절이 보이지 않습니다.

### 서리 유리 (읽기 면)

자막과 종합 판단 본문처럼 길게 읽는 면입니다. 짙은 바탕 58% 에 `blur(22px) saturate(1.2)` 를 걸고, 안쪽 위 1px
흰색 18% 와 안쪽 1px 흰색 8% 테두리를 둡니다. 비치지만 글자 뒤가 흔들리지 않습니다.

### 금테

유리 테두리에 두르는 금속 선입니다. 금색 다섯 단계를 원뿔 그라데이션로 돌려 빛을 받는 금속처럼 보이게 합니다.

| 굵기 | 쓰는 곳 |
|---|---|
| 1px | 대부분의 부품. 버튼, 칩, 세그먼트, 판, 입력칸 |
| 1.4px | 콜 바, 세그먼트 썸처럼 위에 떠 있는 부품 |
| 2.2px | 주문 시트처럼 한 화면의 중심이 되는 판 |

금테는 장식이므로 뜻을 싣지 않습니다. 상태나 결과를 금테 굵기로 구분하지 않습니다.

### 색상 유리 (버튼 전용)

색을 덮어 칠하지 않고 빛처럼 더합니다. 가운데는 맑게 두고, 색은 가장자리 테 · 바닥 투과광 · 바깥 글로우에
모읍니다. 어두운 색을 반투명하게 덮으면 바탕과 섞여 탁해지기 때문입니다.

| 층 | 값 (`c` 는 아래 색상 유리 색) |
|---|---|
| 몸체 | 위에서 아래로 `c` 14% → 6% |
| 바닥 투과광 | 아래 가운데에서 퍼지는 `c` 42% |
| 배경 처리 | 굴절 맵 + `blur(1.5px) saturate(1.9) brightness(1.12)` |
| 윗면 반사선 | 안쪽 위 1px, 흰색 90% |
| 가장자리 테 | 안쪽 1px `c` 60%, 안쪽 14px `c` 32% |
| 바닥 빛 | 안쪽 아래 `c` 75% |
| 바깥 글로우 | 아래 6px, 흐림 22px, `c` 50% |
| 반사광 | 위쪽 흰색 34% → 0, 왼쪽 위 흰색 40% |
| 글자 | 흰색, 글자 그림자에 `c` 45% 번짐 |

## 색

### 바탕과 글자

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `bg` | `#1d1e22` | 창 바탕 |
| `ink-1` | `#fbfaf6` | 본문, 제목 |
| `ink-2` | `#fbfaf6` 82% | 보조 문장 |
| `ink-3` | `#fbfaf6` 58% | 시각, 레이블, 비활성 문구 |

유리 위 글자에는 `0 1px 2px` 검정 55% 그림자를 줍니다. 유리 뒤가 밝아져도 대비를 지키기 위해서입니다.

### 금

| 토큰 | 값 |
|---|---|
| `gold-hi` | `#fff1c4` |
| `gold` | `#e2bd62` |
| `gold-lo` | `#8a6420` |

금은 금테와 포커스 테두리에만 씁니다.

### 색상 유리

| 이름 | 값 (RGB) | 버튼의 뜻 | 예 |
|---|---|---|---|
| 라피스 | `92, 140, 255` | 주 행동 | 주문 확인, 콜 화면 열기 |
| 올리브 | `176, 204, 82` | 확인 · 긍정 | 저장하고 시작, 근거 확인 |
| 포르피라 | `232, 102, 192` | 위험하거나 되돌릴 수 없는 행동 | 키 삭제, 실전 모드로 전환 |
| 맑은 유리 | 색 없음 | 보조 행동 | 취소, 관심종목 추가 |

### 가격

| 토큰 | 값 | 뜻 |
|---|---|---|
| `up` | `#ff5a5f` | 상승 |
| `down` | `#5b9bff` | 하락 |

한국 관례대로 상승은 빨강, 하락은 파랑입니다. 가격에만 쓰고 장식이나 다른 뜻에 쓰지 않습니다. 등락은 색과 함께
`▲` `▼` 기호를 붙입니다.

하락 파랑과 라피스는 색이 가깝습니다. 그래서 쓰는 자리를 나눕니다. 하락 파랑은 글자(가격 · 등락)에만 쓰고 면에는
쓰지 않습니다. 라피스는 버튼 면에만 쓰고 글자나 숫자에는 쓰지 않습니다. 매수 · 매도처럼 가격 방향과 이어지는
선택에는 라피스를 쓰지 않습니다.

### 상태

| 토큰 | 값 | 뜻 |
|---|---|---|
| `ok` | 올리브 `#b0cc52` | 정상 · 연결됨 · 체결 |
| `danger` | `#ff8a5c` | 오류 · 실패 · 만료 |
| `caution` | 금 `#e2bd62` | 주의 · 진행 중 |

오류에 빨강을 쓰지 않는 이유는 상승 빨강과 헷갈리기 때문입니다. 상태 색은 글자와 작은 점에만 쓰고 늘 문구와 함께
둡니다. LIVE 처럼 콜 진행을 알리는 표시는 무채색 점멸로 나타냅니다.

### 직전 콜 대조

대조 칩은 맑은 유리이고, 결과는 글자색과 기호로 나타냅니다. 색상 유리는 버튼에만 쓰기 때문에 칩에는 쓰지 않습니다.

| 결과 | 기호 | 글자색 |
|---|---|---|
| 개선 | `+` | 올리브 |
| 후퇴 | `−` | 포르피라 |
| 혼재 | `±` | `ink-2` |
| 변화 없음 | `=` | `ink-3` |
| 새 언급 | `∗` | `ink-3` |

색만으로 구분하지 않습니다. 기호와 문구를 늘 함께 둡니다. 포르피라와 상승 빨강은 색각 이상이 있으면 비슷하게
보일 수 있어서입니다.

`후퇴` 이거나 위험 점수가 높은 항목은 칩 대신 펼친 카드로 보여 줍니다. 맑은 유리 카드에 포르피라 글자로 `− 후퇴 ·
주제` 머리를 달고, 아래에 직전 발언과 이번 발언 원문을 나란히 둡니다.

### 종합 판단

| 항목 | 표시 |
|---|---|
| 실행 판단(권고 행동) | 색 없이 `ink-1` 24px 로 씁니다. 판단의 첫 줄입니다 |
| 실행 조건 | 통과는 올리브 글자, 조건부 보류는 `ink-2`, 차단은 포르피라 글자 |
| 방향(강세 · 약세 · 중립) | 색 없이 글자로만 씁니다. 상승 · 하락 색과 섞이지 않게 하기 위해서입니다 |
| 근거 확인 여부 | 확인은 올리브 글자, 확인하지 못함은 `ink-3` |

## 형태와 간격

**반경**: 바깥 반경에서 안쪽 여백을 뺀 값이 안쪽 반경입니다(동심 곡률). 판은 28px, 주문 시트는 30px, 입력칸은 16px
입니다. 버튼 · 칩 · 세그먼트 · 콜 바는 끝이 둥근 캡슐입니다.

**간격**: 4px 단위로 4 · 8 · 12 · 16 · 24 · 32 를 씁니다. 버튼 안쪽 여백과 아이콘 크기도 4px 단위입니다.

## 움직임

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 스프링 | `cubic-bezier(.3, 1.35, .5, 1)`, 380~400ms | 세그먼트 썸, 패널 등장 |
| 감속 | `cubic-bezier(.2, .8, .2, 1)`, 200ms | 밝기 · 색 변화 |
| 누름 | `scale(.97)` | 모든 버튼 |
| 올림 | 밝기 1.14~1.15배 | 버튼 마우스 올림 |

깜빡임과 반복 움직임은 쓰지 않습니다. `prefers-reduced-motion` 이면 전환을 끄고, `prefers-reduced-transparency` 이면
유리를 불투명한 면(짙은 바탕 94%)으로 바꿉니다.

## 컴포넌트

### 버튼

| 종류 | 재질 |
|---|---|
| 주 행동 | 라피스 색상 유리 + 금테 1px |
| 확인 | 올리브 색상 유리 + 금테 1px |
| 위험 | 포르피라 색상 유리 + 금테 1px |
| 보조 | 맑은 유리 + 금테 1px |

| 크기 | 글자 | 안쪽 여백 |
|---|---|---|
| 큰 | 15px | 16px 28px |
| 기본 | 14px | 12px 20px |
| 작은 | 12.5px | 8px 16px |
| 아이콘 | 16px 아이콘 | 44 × 44px, 작은 것은 36 × 36px |

상태는 기본 · 마우스 올림(밝게) · 누름(0.97) · 포커스(`gold-hi` 2px 바깥선, 3px 띄움) · 비활성(채도 20%, 밝기 80%,
불투명도 55%)입니다.

대화상자에서는 보조 버튼을 왼쪽, 색상 유리 버튼을 오른쪽에 둡니다.

### 칩

맑은 유리 캡슐에 금테 1px 입니다. 글자는 12px · 650 이고, 직전 콜 대조 칩은 위 대조 색 규칙을 따릅니다.

### 세그먼트

맑은 유리 트랙(금테 1px) 안에서 썸이 스프링으로 미끄러집니다. 썸은 맑은 유리에 금테 1.4px 입니다. 색상 유리는
버튼에만 쓰므로 썸에는 쓰지 않습니다. 고른 칸의 글자는 650 굵기로 올립니다.

### 판 · 콜 바 · 시트

판은 맑은 유리 + 금테 1px, 콜 바는 맑은 유리 캡슐 + 금테 1.4px, 주문 시트는 맑은 유리 + 금테 2.2px 입니다.
자막과 판단 본문은 서리 유리 면입니다.

## 문구 규칙

말투는 [브랜드 문서](brand.md)의 말투 절을 따릅니다. 화면 문구의 세부 표기는 아래와 같습니다.

| 항목 | 규칙 | 예 |
|---|---|---|
| 가운뎃점 | 앞뒤를 한 칸씩 띄웁니다 | `Walmart · Q2 FY27` |
| 음수 · 감소 | 하이픈 대신 마이너스 기호 `−` 를 씁니다. 숫자에는 붙이고, 칩의 기호와 낱말 사이는 띄웁니다 | `−3%p`, `− 후퇴` |
| 비율 변화 | 퍼센트포인트는 `%p` 로 씁니다 | `+0.5%p` |
| 가격 | 달러 기호와 소수 둘째 자리까지 씁니다 | `$97.40` |
| 시각 | 한국 시간으로 쓰고, 필요하면 미국 동부 시간을 덧붙입니다 | `오후 9:00 KST (미 동부 오전 8:00)` |
| 경과 시간 · 자막 시각 | `mm:ss`, 60분을 넘으면 `h:mm:ss` | `02:00`, `1:04:30` |
| 버튼 | 무엇이 일어나는지를 명사구나 짧은 동사구로 씁니다 | `주문 확인`, `콜 화면 열기` |

## 접근성

- 본문 글자는 바탕 대비 4.5:1 이상을 지킵니다. 유리 위 글자는 글자 그림자로 이 대비를 유지합니다.
- 색만으로 뜻을 구분하지 않습니다. 가격은 `▲` `▼`, 대조는 `+` `−` 기호를 함께 둡니다.
- 키보드 포커스는 금색 바깥선으로 늘 보이게 합니다.
- 움직임 줄이기 · 투명도 줄이기 설정을 따릅니다.
