# 홈

로그인 뒤 처음 보이는 화면입니다. 시장 전체보다 내 종목의 어닝콜을 먼저 보여 주고, 시연 재생의 유일한
진입점입니다. 흐름과 이유는 [UX 문서](../ux.md)의 콜 준비 · 시연 흐름에, 재질과 색은
[디자인 시스템](../design-system.md)에 있습니다.

코드는 `trading-terminal/src/renderer/pages/HomePage.tsx`(경로 `/home`)에 있습니다.

## 구성

| 위치 | 영역 | 내용 |
|---|---|---|
| 머리 | 제목 · 시연 | 제목 `홈`, 오른쪽에 시연 종목 안내와 `시연 재생` |
| 주인공 열 | 진행 중인 콜 | 진행 중인 콜이 있을 때만 나타납니다 |
| 주인공 열 | 내 종목의 다가오는 콜 | 관심 · 보유 종목의 예정된 콜을 시각 순으로 |
| 주인공 열 | 전체 일정 | 오늘 · 내일 · 이번 주 · 다음 주 · 이후 묶음. 8행씩 페이지로 넘깁니다 |
| 주인공 열 | 지난 콜 | 자리만 둡니다 |
| 보조 열 | 계좌 | 계좌 종류, 총자산, 오늘 손익, 주문 가능 금액, 보유 종목 수, `포트폴리오에서 자세히` |
| 보조 열 | 시장 | 시장 지수와 등락 |

각 영역은 맑은 유리 판에 금테 1px 입니다. 진행 중인 콜 판만 한 단계 굵은 금테(1.4px)로 띄웁니다.

## 영역

### 시연 재생

`시연 재생` 을 누르면 시연 종목(WMT)의 콜 화면이 열리고 재생이 바로 시작됩니다. 시연 종목은 코드에
고정되어 있어(`constants/demo.ts`) 다른 종목에서 재생하는 실수가 없습니다. 콜 화면의 콜 바에는 시작 버튼이
없고, 시연 중일 때만 `중지` · `처음부터` 가 보입니다.

색상 유리 주 버튼은 화면에 하나이므로, 진행 중인 콜이 있으면 그 판의 `콜 화면 열기` 가 라피스이고
`시연 재생` 은 맑은 유리입니다. 진행 중인 콜이 없으면 `시연 재생` 이 라피스입니다. 계좌 판의
`포트폴리오에서 자세히` 는 예외로 색을 채운 올리브(`gbtn-strong`)입니다. 맑은 유리로는 보조 열에서 눈에 띄지
않아 사용자 요청으로 바꿨습니다.

### 진행 중인 콜

서버가 예정 시각 창으로 추정한 콜입니다. 실제로 시작했는지는 콜 화면의 자막으로만 알 수 있어
"예정 시각 기준으로 진행 중인 것으로 보입니다" 라고 씁니다. LIVE 는 무채색 점멸입니다.

### 콜 목록

- 한 행은 시각 · 티커 · 회사명 · 관심/보유 표시 · 알림 자리입니다. 행을 누르면 [종목 브리핑](stock-brief.md)이
  열리고, 콜 화면은 브리핑의 `콜 화면 열기` 로 들어갑니다.
- 관심과 보유가 겹치면 `보유` 로 표시합니다.
- 시각은 한국 시간입니다. 오늘 · 내일 묶음은 시각만, 그 밖은 날짜와 시각을 씁니다.
- 일정 데이터에는 EPS 기대치가 없어 목록에 넣지 않습니다. 기대치는 종목 브리핑에서 봅니다.
- 알림 자리(종 모양)는 콜 시작 알림 기능이 생길 때까지 흐리게 둡니다.
- 전체 일정은 시즌에 수백 건이라 8행씩 페이지로 나눠 아래 페이지 버튼으로 넘깁니다. 판 높이는 한 페이지
  분량으로 고정해 마지막 페이지가 짧아도 페이지 버튼이 움직이지 않습니다. 묶음이 페이지를 넘어가면 다음
  페이지 맨 위에 묶음 제목을 다시 붙이고 `· 이어서` 를 씁니다. 묶음 옆 숫자는 묶음 전체 건수입니다.

### 계좌

- 계좌 종류는 주문 시트와 같은 문구입니다: KIS 모의투자 · KIS 실전투자 · 페이퍼 계정. 모르면 "계좌 확인 중".
- 총자산은 예수금 + 보유 평가금액(실시간 가격, 없으면 잔고 응답의 가격)입니다.
- 오늘 손익은 보유 종목의 전일 종가 대비입니다. 전일 종가를 모르는 종목이 있으면 `—` 로 둡니다.
- 자산 추이와 보유 표는 포트폴리오의 자산 · 보유 탭에서 봅니다.

## 상태

| 영역 | 불러오는 중 | 비어 있음 | 실패 |
|---|---|---|---|
| 콜 목록 | 흐린 막대 | 관심 · 보유가 없으면 `종목 찾기`, 예정된 콜이 없으면 그 문구 | "실적 콜 일정을 불러오지 못했습니다" + `다시 시도` |
| 계좌 | 흐린 막대 | — | 처음부터 실패하면 문구 + `다시 시도`. 이전 값이 있으면 값을 두고 "동기화 실패 · HH:MM 값" + `다시 시도` |
| 시장 | — | "시장 지수를 아직 받지 못했습니다" | 비어 있음과 같습니다(지수 조회 실패는 알림으로 따로 뜹니다) |

## 표시 데이터

| 영역 | 출처 |
|---|---|
| 콜 일정 · 진행 중인 콜 | `EARNINGS_TIMELINE_GET` + `EARNINGS_TIMELINE_UPDATE` (`useEarningsTimeline`) |
| 관심 종목 | `useWatchlist` |
| 보유 · 예수금 | `KIS_GET_BALANCE` → 잔고 store. 이 화면이 들어올 때 한 번 동기화하고 보유 종목을 시세 폴링에 등록합니다(`HOLDINGS_TICKERS_UPDATE`) |
| 가격 · 전일 종가 | `usePrices` |
| 계좌 종류 | 로그인 응답의 계좌 종류, `SETTINGS_GET_PAPER_TRADING` (`useOrderAccount`) |
| 시장 지수 | `useMarketIndices` |
| 시연 종목 회사명 | S&P 500 목록 (`useStockMarketStore`) |
