# 설정

KIS 연동과 앱 설정을 모아 두는 화면입니다. 주문할 계좌를 고르고, KIS 키를 등록 · 수정 · 삭제하고, 연결 상태를
확인합니다. 흐름과 이유는 [UX 문서](../ux.md)의 처음 시작 · 주문 흐름에, 재질과 색은
[디자인 시스템](../design-system.md)에 있습니다.

코드는 `trading-terminal/src/renderer/pages/SettingsPage.tsx`(경로 `/settings`),
`components/settings/KisKeyForm.tsx`, `components/settings/KisStatusTimeline.tsx` 에 있습니다.

## 들어오는 길

- 메뉴의 `설정`
- 주문 시트의 `KIS 키 등록` — `/settings?kis=paper` 또는 `?kis=real` 로 열고, 그 계좌의 등록 칸을 펼친 채로
  화면 안으로 끌어옵니다

## 영역

위에서부터 제목 `설정`, KIS 연동 판, 앱 설정 판을 둡니다. 판은 맑은 유리 + 금테입니다.

### KIS 연동

로그인 계좌가 페이퍼 계정이면 이 판 대신 "페이퍼 계정 · 준비됨" 판을 둡니다. 페이퍼 계정은 키 없이 현재가로
가상 체결합니다.

| 순서 | 내용 |
|---|---|
| 머리 | 제목 `KIS 연동`, 오른쪽에 연결 상태(`연결 정상` 정상색 · `연결 대기` 주의색) |
| 주문할 계좌 | 전환 `KIS 모의투자 \| KIS 실전투자`. 실전투자를 쓰는 동안(키가 없어도) 옆에 주의색 글자로 "실제 돈으로 주문합니다" |
| 연결 단계 | API 키 → 액세스 토큰 → 서버 연결 세 단계. 된 단계는 정상색, 만료는 오류색, 아직 안 된 단계는 흐린 글자색 |
| API 키 | `KIS 모의투자` · `KIS 실전투자` 두 행. 지금 쓰는 계좌에 `사용 중` |
| 보안 안내 | 키와 토큰을 운영체제 자격 증명 저장소에 암호화해 저장한다는 한 줄 |
| 아래 | `토큰 재발급`(보조), `KIS 개발자 포털 열기`(자리만) |

**주문할 계좌**

- 바꿀 계좌에 키가 있을 때만 바꿀 수 있습니다. 지금 계좌의 키를 지운 뒤에도 키가 있는 계좌로 빠져나올 수 있게
  하기 위해서입니다. 바꿀 계좌에 키가 없으면 흐리게 막고 "다른 계좌의 키도 등록하면 바꿀 수 있습니다", 둘 다
  없으면 "아래에서 키를 등록하면 주문할 수 있습니다" 를 씁니다.
- 바꾸기 전에 대화상자로 묻습니다. 실전투자로 바꾸는 확인은 위험 행동(포르피라), 모의투자로 바꾸는 확인은 올리브입니다.
  바꾸면 토큰을 다시 발급합니다.
- 활성 모드를 읽기 전에는 "주문할 계좌를 확인하는 중입니다" 로 두고 전환과 키 삭제를 막습니다. 삭제 결과(자동 전환 여부)를 판단할 수 없기 때문입니다. 읽지 못하면 오류 알림을 띄우고 막힌 채로 둡니다. 키 등록 · 수정은 막지 않습니다.

**API 키 행**

| 상태 | 표시 | 행동 |
|---|---|---|
| 등록됨 | 가린 계좌번호 · 가린 App Key(고정폭 숫자), HTS ID 는 `등록됨` · `없음` 만 | `수정` · `삭제` |
| 없음 | "등록된 키가 없습니다" | `등록` |

- 등록된 키인데 가린 값을 아직 받지 못했으면 `수정` 을 막고 폼을 펼치지 않습니다(`?kis=` 로 들어온 경우에도 행의 버튼은 남깁니다). 빈 폼으로 열려 저장된 HTS ID 가 지워지지 않게
  하기 위해서입니다.
- `등록` · `수정` 을 누르면 행 아래에 서리 유리 면으로 입력 폼을 펼칩니다. 한 번에 한 행만 펼칩니다. 폼은
  [로그인 화면](login.md)의 키 등록 권유와 같은 폼이고, 버튼은 `취소`(맑은 유리) · `저장`(올리브)입니다.
- 수정에서는 비워 둔 칸이 지금 값을 그대로 씁니다. App Secret 은 화면에 되돌려 받지 않으므로 바꿀 때만 입력합니다.
  HTS ID 는 지금 값이 미리 채워져 있어 지우면 삭제됩니다.
- 삭제는 대화상자로 묻고, 확인 버튼은 위험 행동입니다. 결과는 아래와 같습니다.

| 삭제한 키 | 결과 |
|---|---|
| 지금 쓰지 않는 계좌 | 지금 계좌는 그대로입니다 |
| 지금 쓰는 계좌, 다른 계좌 키 있음 | 다른 계좌로 바뀌고 토큰을 다시 발급합니다. 실전투자로 바뀌면 대화상자에 실제 돈으로 주문한다는 문장을 덧붙입니다 |
| 지금 쓰는 계좌, 남는 키 없음 | 설정에 머물고 키 없음 상태로 표시합니다. 분석 기능은 그대로 씁니다 |

### 앱 설정

알림 · 테마 · 언어 · 자동 로그인 네 자리를 둡니다. 모두 아직 없는 기능이라 흐린 점선 자리에 기능 이름과 한 줄
안내만 씁니다.

| 자리 | 안내 |
|---|---|
| 알림 | 콜 시작 · 체결 알림을 고르는 기능은 준비 중입니다 |
| 테마 | 지금은 어두운 테마만 있습니다 |
| 언어 | 지금은 한국어만 있습니다 |
| 자동 로그인 | 로그인 정보를 보관하는 방식을 정한 뒤 추가합니다 |

## 표시 데이터

| 영역 | 출처 |
|---|---|
| 주문할 계좌 | `SETTINGS_GET_PAPER_TRADING`, 바꿀 때 `SETTINGS_SET_PAPER_TRADING` |
| 키 등록 여부 | `VAULT_HAS` (연결 store 의 `hasCredentials` 도 함께 갱신) |
| 가린 키 | `VAULT_GET_MASKED` — App Secret 은 포함되지 않습니다 |
| 키 저장 · 삭제 | `VAULT_SAVE` · `VAULT_DELETE` |
| 토큰 상태 | 연결 store 의 `kisTokenStatus`, `KIS_TOKEN_REFRESHED` 알림, `KIS_ISSUE_TOKEN` |
| 계좌 종류 | 로그인 응답의 계좌 종류 (`useUserStore`) |

키 등록 여부와 가린 키는 화면을 열 때와 저장 · 삭제 뒤에 다시 불러옵니다. 불러오지 못하면 직전 표시를 남깁니다.

## 아직 정하지 않은 것

- 앱 설정 네 항목의 실제 동작
- `KIS 개발자 포털 열기` — 외부 주소를 여는 경로를 정한 뒤 연결합니다
- 페이퍼 계정과 KIS 계정을 이 화면에서 바꿀 수 있게 할지 — [UX 문서](../ux.md)의 자체 페이퍼 계정 항목 참고
