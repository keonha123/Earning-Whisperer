# 종목 브리핑

어느 화면에서나 오른쪽에 여는 패널입니다. "이 종목의 다음 콜을 들을 준비" 에 필요한 것을 위에서부터 두고,
아래 행동 줄에서 콜 화면으로 들어갑니다. 흐름은 [UX 문서](../ux.md)의 콜 준비에 있습니다.

코드는 `trading-terminal/src/renderer/components/dashboard/CompanyDrawer.tsx` 이고, 앱 셸에 하나만 붙어 있어
`useDrawerStore.open(ticker)` 로 엽니다.

## 들어오는 길

- 홈의 콜 행
- 종목 화면의 종목 행
- 포트폴리오의 보유 종목 행
- 콜 화면 콜 바의 종목 정보, 종합 판단의 파급 영향 종목

화면을 옮기면 닫힙니다. 닫기 버튼, Esc, 바깥 클릭으로도 닫힙니다.

## 구성

서리 유리 판입니다. 위에서부터:

| 순서 | 영역 | 내용 |
|---|---|---|
| 머리 | 종목 | 로고, 티커, 회사명, 현재가(실시간 가격이면 "실시간"), `지원 외` · `일부 동기화 중` 표시 |
| 1 | 다음 콜 | 남은 시간(하루 안이면 시간 · 분, 30초마다 갱신), 확정 · 예정, KST 일시와 미 동부 시각, EPS · 매출 컨센서스 |
| 2 | 최근 어닝 반응 | 분기별 EPS 예상 → 실제, 발표일 주가 반응(최근 분기부터) |
| 3 | 30일 종가 | 기간 등락, 마지막 거래일 등락, 선 그래프 |
| 4 | 기본 정보 | 섹터, 시가총액, 52주 고가 · 저가, 배당수익률 |
| 5 | AI 요약 | 자리만 둡니다 |
| 행동 줄 | | `관심 추가` / `관심 해제`(맑은 유리), `콜 화면 열기`(라피스, 이 패널의 주 버튼) |

`콜 화면 열기` 는 그 종목의 콜 화면에서 연 브리핑에는 두지 않습니다. 브리핑은 화면 위에 따로 열리는 판이라
주문 시트처럼 그 안에서 색상 유리 주 버튼을 따로 셉니다.

- 다음 콜과 최근 어닝 반응을 앞에 두는 이유는 이 패널이 콜을 듣기 전의 판단 자료이기 때문입니다. 기본 정보는
  콜과 직접 관계가 적어 뒤로 보냈습니다.
- 등락 숫자와 그래프 선만 상승 빨강 · 하락 파랑이고, 변화가 없으면 무채색입니다. 확정 · 예정, 지원 외 같은 표시는 무채색 글자입니다.
- S&P 500 밖 종목은 다음 콜 · 최근 어닝 반응 자리에 "어닝 분석은 S&P 500 종목만 지원합니다" 를 씁니다.

## 상태

| 상태 | 표시 |
|---|---|
| 불러오는 중 | 머리(티커)와 흐린 막대 |
| 실패 | 머리(티커)와 "종목 정보를 불러오지 못했습니다" |
| 일부 데이터 없음 | 그 섹션에 "아직 받지 못했습니다" 문구 |

## 표시 데이터

| 영역 | 출처 |
|---|---|
| 종목 정보 전체 | `STOCK_GET_DETAIL` (`useCompanyDetail`) |
| 현재가 | 시세 갱신 (`usePrices`), 없으면 종목 정보의 현재가 |
| 관심 여부 · 추가 · 해제 | `useWatchlist`, `WATCHLIST_ADD` / `WATCHLIST_REMOVE` |

## 아직 정하지 않은 것

- AI 요약(지난 콜 요약) — 데이터가 없습니다
- 브리핑에서 바로 주문 열기 — 주문은 지금 콜 화면에서만 엽니다
