# 포트폴리오

내 계좌의 자산과 거래 내역을 보는 화면입니다. 홈이 어닝콜 중심이 되면서 예전 대시보드에 있던 자산 정보와 별도
메뉴였던 체결 내역을 이 화면의 두 탭으로 모았습니다. 메뉴와 흐름은 [UX 문서](../ux.md)에, 재질과 색은
[디자인 시스템](../design-system.md)에 있습니다.

코드는 `trading-terminal/src/renderer/pages/PortfolioPage.tsx`(경로 `/portfolio`)와 `components/portfolio/`,
거래 내역 탭의 `pages/HistoryPage.tsx` 에 있습니다.

## 들어오는 길

- 메뉴의 `포트폴리오`
- 홈의 계좌 요약(홈 화면 #156 에서 연결합니다)
- 다른 화면에서 거래 내역으로 바로 보낼 때는 `/portfolio?tab=history` 를 씁니다

## 탭

| 탭 | 주소 | 내용 |
|---|---|---|
| 자산 · 보유 | `/portfolio` | 계좌 요약, 자산 추이, 보유 종목 |
| 거래 내역 | `/portfolio?tab=history` | 주문 · 체결 기록, 필터, CSV |

탭은 화면 제목 옆의 세그먼트로 바꿉니다. 고른 탭은 주소에 남아 뒤로 가기와 바로 가기가 같은 탭을 엽니다.

## 자산 · 보유

예전 대시보드의 캐러셀 4장(자산 현황 · 종목 비중 · 일간 손익 · 미실현 손익)을 넘겨 보지 않아도 되게 한 화면에
펼쳤습니다. 합계는 계좌 요약으로, 종목별 손익과 비중은 보유 표의 열로 옮겼습니다. 관심 종목은 홈과 종목
화면이 맡아 이 화면에 두지 않습니다.

### 계좌 요약

맑은 유리 판입니다.

| 위치 | 내용 |
|---|---|
| 머리 | 계좌 종류(KIS 모의투자 · KIS 실전투자 · 페이퍼 계정), 마지막 동기화 시각, `동기화` |
| 위 | 총자산 |
| 가운데 | 미실현 손익(금액 · 수익률), 일간 손익 |
| 아래 | 현금 · 주식 비중 막대, 현금 · 평가금액 · 주문가능 금액 |

- 계좌 종류를 아직 모르면 "계좌 확인 중" 으로 둡니다.
- 일간 손익은 홈과 같은 규칙입니다. 보유 종목 중 하나라도 전일 종가를 모르면 일부 합이 전체로 읽히지 않게 `—` 로 둡니다.
- 현금 · 주식 비중 막대는 범주라서 무채색 단계로 나눕니다. 가격색과 상태색을 쓰지 않습니다.

### 자산 추이

맑은 유리 판입니다. 계좌를 동기화할 때 하루 한 건씩 쌓이는 자산 기록을 선 그래프로 그립니다. `7일 · 30일 ·
90일` 세그먼트로 기간을 바꾸고, 시작 · 고점 · 저점 · 기간 손익을 위에 둡니다. 선 색은 기간 손익의 방향을
따르고, 변동이 없으면 무채색입니다. 기간 손익은 입출금이 섞인 자산 변화량입니다.

### 보유 종목

서리 유리 판입니다.

| 열 | 내용 |
|---|---|
| 종목 | 로고, 티커, 회사명 |
| 수량 · 평균가 · 현재가 | 현재가는 시세 갱신 값을 먼저 쓰고, 없으면 잔고 응답의 현재가를 씁니다 |
| 일간 | 전일 대비 등락률. 전일 종가를 모르면 `—` |
| 평가금액 · 비중 | 비중은 현금을 포함한 총자산 대비입니다 |
| 미실현 손익 | 금액과 수익률 |
| 다가오는 콜 | 진행 중이면 `진행 중`, 예정이면 한국 시간 날짜와 `오늘 · 내일 · N일 후`. 이미 지난 일정이 남아 있으면 `지난 일정` |

- 행을 누르면 종목 브리핑이 오른쪽 패널로 열립니다. 키보드와 화면 낭독기는 종목 셀의 버튼으로 엽니다.
- 등락과 손익은 상승 빨강 · 하락 파랑에 `▲` `▼` 기호나 부호를 함께 씁니다.
- 콜 진행 표시는 무채색 점이고 깜빡이지 않습니다.

## 거래 내역

예전 체결 내역 화면의 기능을 그대로 옮기고 새 재질과 상태 패턴을 입혔습니다.

| 위치 | 내용 |
|---|---|
| 위 | `오늘` · 매수 · 매도 건수 칩(지금은 이번 페이지 기준 집계), 마지막 업데이트 시각, `새로고침` |
| 필터 | 전체 · 매수 · 매도 · 실패만 세그먼트, 기간, 종목, 티커 검색, `CSV 내보내기` |
| 표 | 일시, 종목, 방향, 체결수량, 체결가, 체결금액, 상태, 상세 `보기` |
| 아래 | 건수(지금은 이번 페이지 기준), 페이지 이동, 페이지당 행 수 |

- 화면을 열 때와 `새로고침` 때 접수 상태 주문을 KIS 에 다시 조회해 상태를 맞춘 뒤 목록을 읽습니다.
- 방향은 `▲ 매수`(상승 빨강) · `▼ 매도`(하락 파랑)로 씁니다. 상태는 체결(정상색) · 대기(주의색) · 실패(오류색)
  점과 글자입니다.
- `보기` 는 거래 상세 대화상자를 엽니다. Esc, 닫기, 바깥 클릭으로 닫힙니다.
- 일시 · 체결가 · 체결금액의 정렬 표시는 자리만 둡니다. 누르면 "정렬은 준비 중입니다" 를 알립니다.
- `CSV 내보내기` 는 지금 거른 행을 저장합니다. 거른 행이 없으면 비활성입니다.

## 상태

| 상황 | 표시 |
|---|---|
| 잔고를 아직 받지 못함 | 계좌 요약과 보유 표 자리에 흐린 막대 |
| 잔고 조회 실패, 받아 둔 값 있음 | 마지막 값을 흐리게 남기고 판 위에 실패 사유 · 마지막 조회 시각 · `다시 조회` 를 덮습니다 |
| 잔고 조회 실패, 받아 둔 값 없음 | 0 을 값처럼 보이지 않게 "잔고를 불러오지 못했습니다" 와 `다시 조회` 만 둡니다 |
| 보유 종목 없음 | "보유 종목이 없습니다. 주문이 체결되면 여기에 표시됩니다." |
| 자산 기록 없음 | "최근 N일간 자산 기록이 없습니다" 와 기록이 쌓이는 때 |
| 자산 추이 실패 | 받아 둔 추이가 있으면 남기고 위에 실패 문구와 `다시 시도`. 다른 기간을 고르다 실패하면 남은 추이가 어느 기간인지 씁니다. 없으면 실패 문구와 `다시 시도` 만 둡니다 |
| 콜 일정 실패 | 보유 표 머리에 실패 문구와 `다시 시도` |
| 거래 내역 불러오는 중 | 표 자리에 흐린 행 |
| 거래 내역 실패, 받아 둔 목록 있음 | 목록을 남기고 표 위에 실패 띠(마지막으로 받은 시각 · `다시 시도`) |
| 거래 내역 실패, 받아 둔 목록 없음 | 표 안에 실패 문구와 `다시 시도` |
| 거래 내역 없음 | 기간에 거래가 없을 때와 필터에 맞는 행이 없을 때를 다른 문구로 씁니다 |

잔고 · 거래 내역 조회 실패의 사유는 화면 오른쪽 위 알림으로 알립니다. 인증이 만료되었으면 알림의
`다시 로그인` 이 로그인 화면으로 보냅니다.

## 표시 데이터

| 영역 | 출처 |
|---|---|
| 잔고 · 보유 | `KIS_GET_BALANCE` → 잔고 store (`usePortfolioStore`). 화면에 들어올 때 한 번 다시 조회하고, 성공하면 `HOLDINGS_TICKERS_UPDATE` 로 시세 폴링 대상을 알립니다 |
| 현재가 · 전일 종가 | 시세 갱신 (`usePrices`) |
| 회사명 | S&P 500 목록 (`useStockMarketStore`), 로고 색은 `COMPANY_META` |
| 자산 추이 | `KIS_GET_ASSET_TIMESERIES` |
| 다가오는 콜 | `EARNINGS_TIMELINE_GET` · `EARNINGS_TIMELINE_UPDATE` (`useEarningsTimeline`) |
| 계좌 종류 | 로그인 응답의 계좌 종류, `SETTINGS_GET_PAPER_TRADING` |
| 거래 내역 | `TRADES_RECONCILE_PENDING` 뒤 `TRADES_GET`, CSV 는 `SHELL_SAVE_CSV` |

## 아직 정하지 않은 것

- 거래에서 그 거래를 낸 콜로 가는 연결 — 지난 콜 저장이 먼저 필요합니다
- 거래 내역 정렬
- 거래 내역 요약 칩의 수치와 실패 사유 표시 — 지금은 이번 페이지 기준 집계이고, 실패 사유는 화면이 아직
  받아 오지 않습니다
