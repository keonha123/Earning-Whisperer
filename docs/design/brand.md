# 브랜드

Logothea 의 이름, 표기, 브랜드 성격, 말투, 로고 사용 기준을 정리한 문서입니다. 화면 문구를 쓰거나 로고 · 아이콘 ·
UI 컨셉을 정하는 기여자를 위한 문서입니다. 색 · 타이포 같은 시각 기준은 [디자인 시스템](design-system.md)에서 다룹니다.

## 이름

### 유래

그리스어 λόγος(로고스)는 "말" 과 "회계 · 셈" 을 함께 뜻합니다. 그래서 λόγον διδόναι(로곤 디도나이)는
"설명을 내놓다" 로도 "셈을 내놓다" 로도 읽힙니다. 어닝콜이 바로 그 자리입니다. 경영진이 한 분기의 셈을 내놓고
설명하는 시간입니다.

여기에 τίθημι(티테미, "놓다 · 세우다")가 붙은 λογοθέτης(로고테테스)는 비잔틴 제국의 고위 관직 이름이었고,
그중 여럿이 국가의 재정과 셈을 살폈습니다. 문자 그대로 "셈을 세우는 사람" 입니다.

Logothea 는 그 말에서 나온 이름입니다. 경영진의 말과 숫자를 나란히 놓고 살피는 일, 지난 분기의 말을 잊지 않고
대조하는 일을 개인투자자 대신 합니다.

한 문장으로 소개할 때는 이렇게 씁니다.

> 그리스어로 말과 회계는 같은 단어였고, 로고테아는 그 셈을 살피던 사람의 이름에서 왔습니다.

### 표기

| 쓰는 곳 | 표기 |
|---|---|
| 문장 속, 문서, 발표 | `Logothea`. 첫 글자만 대문자입니다 |
| 앱 이름 (설치 파일, 창 제목, 트레이, 작업 표시줄) | `Logothea`. 지금 붙어 있는 `Terminal` 접미사는 붙이지 않습니다 |
| 한글 | `로고테아`. 문서와 소개에서 처음 나올 때 `Logothea(로고테아)` 로 한 번 병기합니다. 앱 화면과 로고에는 쓰지 않습니다 |
| 워드마크 | `Logothea` 하나만 씁니다. 모양은 아래 [로고와 앱 아이콘](#로고와-앱-아이콘) 절을 따릅니다 |
| 도메인 | `logothea.com` (소문자) |

`LogoThea`, `LOGOTHEA`, `로고 테아` 처럼 나누거나 바꿔 쓰지 않습니다.

### 이전 이름

이전 이름은 EarningWhisperer 입니다. 저장소 이름, 패키지 이름, 코드 식별자에는 아직 이전 이름이 남아 있습니다.
화면과 문서에 보이는 이름부터 Logothea 로 바꿉니다. 이름을 바꿀 때 주의할 곳은 아래와 같습니다.

| 위치 | 주의할 점 |
|---|---|
| `electron-builder.ts` 의 `productName` | 설치 파일 이름과 설치 경로가 바뀝니다 |
| `electron-builder.ts` 의 `appId` | 바꾸면 Windows 가 다른 앱으로 인식해 기존 설치와 바로가기가 따로 남습니다 |
| `KEYTAR_SERVICE` (`index.ts`, `settingsHandlers.ts`, `KisService.ts`, `KisWebSocketService.ts` 와 테스트에 각각 선언) | 자격 증명 저장소의 서비스 이름입니다. KIS 키 · 계좌번호 · HTS ID · 액세스 토큰 · 모의/실전 설정이 모두 이 이름 아래 있습니다. 바꾸면 저장한 값을 찾지 못해 키를 다시 등록해야 하고, 실전으로 설정한 사용자도 기본값인 모의로 돌아갑니다. 선언이 여러 곳이라 한 번에 같이 바꿔야 합니다 |
| 창 제목(`renderer/index.html` 의 `<title>`), 트레이 툴팁 | 화면에 보이는 이름입니다 |
| 로그인 화면(`AuthBrandSection`), 메뉴 위 브랜드(`LeftSidebar` 의 이름 · `EW` 모노그램 · `Trading Terminal` 부제) | 화면에 보이는 이름입니다. 모노그램은 로고(#129)가 정해진 뒤 바꿉니다 |
| OAuth 로그인 뒤 브라우저에 뜨는 결과 페이지(`OAuthService`) | 브라우저 탭 제목에 보이는 이름입니다 |
| `package.json` 의 `description` · `author` | 화면에는 보이지 않지만 설치 정보에 남습니다 |

## 브랜드 성격

이름의 유래에서 성격을 가져옵니다. 로고와 앱 이름에는 고전에서 온 절제를 담고, 앱 화면은 차분하고 정밀한
현대 분석 도구로 만듭니다.

| 성격 | 뜻 | 화면과 문구에서 |
|---|---|---|
| 엄정함 | 셈을 바로 세웁니다. 확인한 것과 확인하지 못한 것을 구분합니다 | 근거가 없으면 없다고 씁니다. 숫자는 출처와 함께 둡니다 |
| 대조 | 말과 숫자를, 이번 분기와 지난 분기를 나란히 놓습니다 | 변화는 "무엇에서 무엇으로" 를 함께 보여 줍니다 |
| 기록 | 지난 말을 잊지 않습니다 | 지난 발언 원문을 요약 대신 그대로 보여 줄 자리를 둡니다 |
| 차분함 | 시장이 흔들려도 화면은 흔들리지 않습니다 | 강조는 정말 필요한 곳에만 씁니다. 깜빡임과 과한 움직임을 쓰지 않습니다 |

하지 않는 것은 아래와 같습니다.

- 매수 · 매도를 부추기는 말투. 판단은 사용자가 합니다
- 확신을 부풀리는 표현 ("확실한", "놓치면 안 될")
- 게임처럼 만드는 요소 (점수 경쟁, 축하 효과)
- 흔한 핀테크 시각 관습을 그대로 따르는 것 (네온 그라데이션, 과장된 상승 연출)

## 말투

| 상황 | 기준 | 예 |
|---|---|---|
| 안내 · 설명 | 습니다체로 사실을 먼저 씁니다 | "직전 콜에서는 26% 성장이라고 했습니다." |
| 판단 결과 | 결론과 근거를 함께, 단정하지 않습니다 | "실행 보류 · 관세 환급 효과를 뺀 이익 증가율 확인이 필요합니다." |
| 오류 | 무엇이 안 됐고 어떻게 하면 되는지 씁니다. 사과로 시작하지 않습니다 | "KIS 토큰이 만료되었습니다. 설정에서 다시 발급할 수 있습니다." |
| 레이블 · 버튼 | 명사나 짧은 동사로 씁니다 | "콜 화면 열기", "주문 보내기" |

문장부호, 숫자, 가운뎃점 띄어쓰기 같은 세부 문구 규칙은 [디자인 시스템](design-system.md)에서 정합니다.

## 로고와 앱 아이콘

로고는 심볼과 워드마크로 이루어집니다. 심볼은 앱 아이콘과 같은 그림입니다(#129).

### 심볼

흰 대리석 타일 위에 금색 L 을 세우고, 금테를 두른 올리브관으로 둘렀습니다.

| 요소 | 모양 | 뜻 |
|---|---|---|
| 바탕 | 신전 기둥의 흰 대리석. 좌우로 옅은 음영을 넣어 기둥의 둥근 면을 나타냅니다 | 고전에서 온 절제 |
| L | 로마 비문 대문자. 굵은 세로획, 가는 가로획, 받침 세리프에 금박 결을 넣고 대리석에 상감한 것처럼 옅은 그림자를 둡니다 | Logothea 의 머리글자, 셈을 바로 세움 |
| 올리브관 | 아래에서 두 가지가 교차하고 위가 열립니다. 잎은 서로 어긋나게 나고, 바깥 잎은 짙은 녹색 앞면, 안쪽 잎은 은녹색 뒷면입니다. 잎 가장자리와 줄기는 금으로 둘렀습니다 | 좌우 두 가지는 말과 셈을 나란히 놓는 대조 |
| 타일 테두리 | 얇은 금테 | 앱 화면의 금테 재질과 같은 언어 |

### 워드마크

`Logothea` 를 Inter SemiBold, 자간 -2.5% 로 씁니다. 글꼴이 없는 환경에서도 같은 모양이 나오도록 글자를
도형으로 바꾼 파일을 씁니다. 워드마크를 글꼴로 다시 입력해 만들지 않습니다.

### 파일

원본은 `docs/design/logo/` 에 있습니다.

| 파일 | 쓰는 곳 |
|---|---|
| `logothea-symbol.svg` | 심볼 단독. 앱 아이콘의 벡터 원본입니다 |
| `logothea-lockup-light.svg` | 밝은 바탕의 가로 조합 (심볼 + 먹색 워드마크) |
| `logothea-lockup-dark.svg` | 어두운 바탕의 가로 조합 (심볼 + 흰색 워드마크) |
| `logothea-wordmark-ink.svg` | 밝은 바탕의 워드마크 단독 (`#1d1e22`) |
| `logothea-wordmark-white.svg` | 어두운 바탕의 워드마크 단독 (`#fbfaf6`) |

### 사용 규칙

- **바탕별 변형**: 심볼은 어느 바탕에서나 같은 그림을 씁니다. 워드마크는 밝은 바탕에서 먹색, 어두운 바탕에서
  흰색을 씁니다. 워드마크에는 금색을 쓰지 않습니다.
- **여백**: 로고 둘레에 심볼 높이의 1/4 이상을 비워 둡니다.
- **최소 크기**: 가로 조합은 높이 24px 이상에서 씁니다. 그보다 작은 자리에는 심볼만 둡니다. 심볼은 32px 이하에서
  올리브관이 질감으로만 남고 흰 타일과 금색 L 이 읽힙니다.
- **쓰지 않는 변형**
  - 심볼이나 L 의 색 바꾸기
  - 타일 없이 올리브관과 L 만 떼어 쓰기
  - 가로세로 비율 바꾸기, 기울이기
  - 그림자 · 빛 · 테두리 같은 효과 덧붙이기
  - 워드마크를 대문자나 다른 글꼴로 바꾸기

### 앱 아이콘

`trading-terminal/resources/icon.png` 는 `logothea-symbol.svg` 를 1024×1024 PNG 로 내보낸 파일입니다.

- 824×824 둥근 사각형(모서리 반지름 185)을 가운데 두고 바깥은 그림자를 빼면 투명합니다. macOS 는 아이콘
  모서리를 자동으로 둥글게 하지 않아서 직접 둥글렸습니다.
- 이 PNG 한 장에서 플랫폼별 `.ico` · `.icns` 가 자동 생성됩니다.
- 트레이는 같은 파일을 18px 로 줄여 씁니다. 그 크기에서는 흰 타일과 금색 L 만 읽히고, 밝은 메뉴 막대에서는
  흰 타일의 윤곽이 약합니다. 트레이 전용 이미지는 따로 만들지 않았습니다.
