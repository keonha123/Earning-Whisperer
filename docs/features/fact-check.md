# 실시간 팩트체크

어닝콜 발언 속 사실 주장을 뉴스 근거와 대조해 판정하는 `발언 검증` 패널을 설명합니다. 판정을 어떻게 읽으면
되는지와 한계를 다루며 앱 사용자와 시연을 보는 평가자를 위한 문서입니다.

## 화면 위치

Trading Room 오른쪽 열 위쪽의 `발언 검증` 패널입니다. 패널 머리에는 받은 카드 수가
`뉴스 N · 지난 분기 N` 형식으로 표시됩니다.

## 동작 방식

서버는 자막 문장을 하나씩 AI 엔진에 보냅니다. AI 엔진은 문장이 세 개 모이면 그 안에서 숫자나 사실 주장을
골라내고, 관련 뉴스를 찾아 주장과 비교한 뒤 판정과 설명을 돌려줍니다. 판정이 끝난 결과만 화면에 도착하므로 문장보다
몇 초 늦게 나타나며 기다리는 동안 패널 아래에 `AI 교차 분석 중...` 이 표시됩니다.

## 판정 종류

| 화면 표시 | 의미 |
|---|---|
| `사실 확인` | 뉴스 근거가 발언 내용을 뒷받침합니다 |
| `사실과 다름` | 뉴스 근거와 발언 내용이 어긋납니다. 예를 들어 "52% 성장" 이라는 발언에 "실제 42%" 라는 근거가 붙으면 이 판정이 나오고 설명에 차이가 적힙니다 |
| `근거 부족` | 판정에 쓸 만한 뉴스 근거를 찾지 못했습니다. 발언이 틀렸다는 뜻이 아닙니다 |

## 판정 카드 읽기

`뉴스 대조` 카드 한 장에는 아래 정보가 위에서부터 표시됩니다.

| 요소 | 설명 |
|---|---|
| `뉴스 대조` 배지와 판정 | 왼쪽에 근거 종류, 오른쪽에 판정이 색으로 표시됩니다 |
| 주장 | 발언에서 골라낸 사실 주장 |
| `→` 설명 | 왜 그렇게 판정했는지 한국어로 적은 설명 |
| 출처 | 근거 뉴스의 매체명과 제목. 마우스를 올리면 근거 본문 일부가 보입니다 |
| `N% 신뢰` | 판정의 신뢰도 |

카드는 발언 순서대로 쌓이고 새 카드가 오면 패널이 아래로 스크롤됩니다.

## 근거 부족 경고

서버에 저장된 근거 뉴스가 너무 적은 상태에서 `시연 시작` 을 누르면 재생은 그대로 시작되고 아래 알림이
함께 나옵니다.

```
근거 뉴스가 N건뿐입니다. 팩트체크가 대부분 '근거 부족'으로 나옵니다. 시연 전 뉴스를 적재하세요.
```

이 알림이 나오면 자막은 정상이지만 판정은 대부분 `근거 부족` 으로 나옵니다. 서버 운영자가 근거 뉴스를
적재해야 해소됩니다.

## 판정이 나오지 않는 경우

- 숫자나 사실 주장이 없는 문장(인사, "좋은 분기였습니다" 같은 수사)은 대부분 검사 대상에서 빠져 카드가
  생기지 않습니다. 일부는 `근거 부족` 카드로 나올 수 있습니다. 세 문장 묶음 전체에 주장이 없으면 그 묶음은
  카드 없이 지나갑니다.
- 문장을 세 개씩 묶기 때문에 콜 끝에 세 개를 채우지 못하고 남은 문장은 검사하지 않습니다. 시연 스크립트는
  24문장이라 남는 문장이 없습니다.
- `시연 시작` 을 다시 누르면 이전 재생의 카드는 지워지고 새로 쌓입니다.

## 시연에서의 정확도

월마트 콜 24문장에서 나온 판정 29건은 `사실 확인` 7건, `사실과 다름` 0건, `근거 부족` 22건입니다
(2026-09-11 측정). 이 중 확인된 한계는 세 가지입니다.

- `사실 확인` 7건 중 2건(가이던스 관련)은 근거 기사에 같은 값이 없는데도 통과했습니다.
- 해당 실행에서 `사실과 다름` 판정은 없었습니다. 이 결과만으로 모든 발언이 정확하다고 입증되지는 않습니다.
- 가장 강한 근거가 콜 당일의 실적 보도라서 이 검증은 "발언한 숫자가 보도와 일치하는가" 를 확인하는 것이지
  독립적인 진위 판별은 아닙니다.

측정 방법과 원인 분석은 [시연 자료](../demo/README.md)에 있습니다.

## 지난 분기 대비

같은 패널의 `지난 분기 대비` 카드는 저장된 직전 콜 원문 문장과 비교한 결과를 보여 줍니다.
원문을 적재할 때 비교할 문장을 추출하고, 대조할 때 선택한 문장 번호를 저장된 원문으로 변환합니다.
명시적으로 다른 지표·사업부·판매 채널·단위의 짝은 제외합니다. 비교 가능한 문장이나 모델 결과가 없으면
카드를 만들지 않으며, 주제가 비슷하다는 이유만으로 같은 지표임을 보장하지는 않습니다.
