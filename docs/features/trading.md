# KIS 주문

한국투자증권(KIS) Open API 로 미국 주식을 주문하는 기능을 설명합니다. 키 등록, 주문, 체결 확인, 키 보관을
차례로 다루며 앱 사용자를 위한 문서입니다. 이 앱은 사용자가 직접 낸 주문만 실행합니다.

## 키 등록

어닝콜 분석과 시연은 키 없이 쓸 수 있고, 키는 주문할 때만 필요합니다. 키는 세 곳에서 등록합니다.

| 화면 | 언제 |
|---|---|
| `주문용 KIS 키 등록` | 이 PC 에 등록된 키가 없는 상태로 로그인했을 때 나옵니다. `나중에` 로 건너뛰면 홈으로 갑니다 |
| 주문 시트의 `KIS 키 등록` | 키 없이 주문을 열었을 때 나옵니다. 누르면 `설정` 에서 그 계좌의 등록 칸이 펼쳐진 채로 열립니다 |
| `설정` → `KIS 연동` → `API 키` | 키를 추가, 수정, 삭제할 때 |

모의투자와 실전투자 키를 따로 등록하며 한쪽만 등록해도 됩니다. 첫 로그인 직후 화면에서는 위쪽 전환으로
`KIS 모의투자` 또는 `KIS 실전투자` 를 골라 한 벌만 입력하고, 고른 계좌가 주문할 계좌가 됩니다. 입력하는 값은
`App Key`, `App Secret`, `계좌번호`, `HTS ID (선택)` 입니다. HTS ID 를 넣으면 체결 통보를 실시간으로 받고, 비워 두면 주문 시트의 `체결 확인` 을
누르거나 `포트폴리오` 의 `거래 내역` 탭을 열거나 새로고침할 때 체결 여부를 확인합니다.

## 모의와 실전 전환

`설정` → `KIS 연동` 의 `주문할 계좌` 전환(`KIS 모의투자` · `KIS 실전투자`)으로 바꿉니다. 바꿀 계좌의 키가
등록되어 있어야 전환을 쓸 수 있고, 바꾸기 전에 확인 대화상자가 나옵니다. 실전투자를 쓰는 동안에는 전환 옆에
`실제 돈으로 주문합니다` 가 표시됩니다.

전환하면 액세스 토큰이 다시 발급됩니다. 실전 환경에서는 실제 계좌로 주문이 체결됩니다.

## 주문

콜 화면 위쪽 콜 바의 `주문` 을 누르면 주문 시트가 열립니다. `주문` 을 다시 누르거나 시트 오른쪽 위 닫기(×) 버튼, Esc, 시트 바깥 클릭으로 닫습니다.

<!-- 스크린샷: 콜 화면의 주문 시트 (계좌, 매수/매도, 수량, 즉시 체결/지정가, 예상 금액, 예수금) -->

시트 맨 위에는 주문할 계좌가 `KIS 모의투자 계좌`, `KIS 실전투자 계좌`, `페이퍼 계정` 가운데 하나로 표시되고,
그 아래에 계좌별 안내 문장이 붙습니다.

1. `매수` 또는 `매도` 를 고릅니다.
2. `수량` 을 입력합니다. `최대` 를 누르면 매수는 예수금으로 살 수 있는 최대 수량, 매도는 보유 수량이 들어갑니다.
3. `즉시 체결` 또는 `지정가` 를 고릅니다. `지정가` 를 고르면 가격 입력칸이 나옵니다.
4. `예상 금액` 과 `예수금` 을 확인하고 `매수 확인` 또는 `매도 확인` 을 누릅니다.
5. `주문을 보낼까요?` 확인 단계에서 계좌, 종목, 방향, 수량, 가격, 예상 금액을 다시 보고 `주문 보내기` 를 누릅니다.
   `취소` 를 누르면 입력으로 돌아갑니다. 실전투자 계좌에서는 `주문 보내기` 가 위험 행동 색으로 표시됩니다.

KIS 해외주식 주문에는 시장가가 없어서 `즉시 체결` 은 현재가에서 1% 불리한 쪽(매수는 위, 매도는 아래)의
지정가로 주문합니다. 예상 금액도 이 가격을 기준으로 계산합니다.

KIS 계좌인데 키가 없으면 입력 대신 `KIS 키 등록` 안내가 나옵니다.

## 체결 확인

주문 직후에는 주문 시트 아래쪽 `이번 세션 주문` 에서 확인합니다. 이 콜 화면에서 낸 주문이 쌓이고, 상태는
`접수`, `체결`, `부분 체결`, `실패` 로 표시됩니다.

`접수` 는 지정가 주문이 체결을 기다리는 상태입니다. HTS ID 를 등록해 KIS 체결 통보를 받으면 상태가 자동으로
바뀝니다. 통보를 받지 못했으면 `체결 확인` 을 눌러 KIS 에 다시 조회합니다.

이 종목의 보유 수량은 가격 카드의 `내 포지션`(`보유`, `평단`, `평가손익`)에서 봅니다. 가격 카드는 콜 시작 전에는
옆 자리에, 콜 진행 중에는 옆 자리 `가격` 탭에 있습니다. 전체 주문 기록은 왼쪽 메뉴 `포트폴리오` 의 `거래 내역`
탭에서 확인합니다.

`거래 내역` 탭은 열 때와 `새로고침` 을 누를 때 접수 상태 주문을 KIS 에 다시 조회해 상태를 맞춥니다.
`전체`, `매수`, `매도`, `실패만` 과 기간, 종목으로 거를 수 있고 `CSV 내보내기` 로 내려받을 수 있습니다.
화면 구성은 [포트폴리오 화면 명세](../design/screens/portfolio.md)에 있습니다.

## 키 보관

- App Key, App Secret, 계좌번호, HTS ID, 액세스 토큰은 Windows 자격 증명 저장소에 `EarningWhisperer`
  이름으로 저장됩니다. 앱은 키를 평문 파일로 남기지 않습니다.
- 주문은 앱이 KIS 서버로 직접 보냅니다. EarningWhisperer 서버는 KIS 를 호출하지 않으며 주문이 끝난 뒤
  주문 기록과 잔고만 받아 저장합니다.
- `설정` 화면의 키 행에는 App Key 와 계좌번호를 가린 형태로 표시하고 App Secret 은 표시하지 않습니다.
  수정할 때 빈칸으로 둔 항목은 기존 값을 그대로 씁니다. HTS ID 는 기존 값이 미리 채워져 있어 지우면 삭제됩니다.
- 지금 쓰는 계좌의 키를 삭제하면 다른 계좌의 키가 있을 때 그 계좌로 바뀌고, 남는 키가 없으면 설정에 머물며
  키 없음 상태로 표시합니다.
- 왼쪽 메뉴 아래쪽의 `KIS` 줄에서 토큰 상태를 `토큰 유효`, `토큰 만료`, `연결 안 됨` 으로 볼 수 있습니다. 정상이
  아닐 때 이 줄을 누르면 `설정` 으로 갑니다. 만료되었으면 `설정` 의 `토큰 재발급` 을 누릅니다.
