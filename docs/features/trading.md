# KIS 주문

한국투자증권(KIS) Open API 로 미국 주식을 주문하는 기능을 설명합니다. 키 등록, 주문, 체결 확인, 키 보관을
차례로 다루며 앱 사용자를 위한 문서입니다. 이 앱은 사용자가 직접 낸 주문만 실행합니다.

## 키 등록

키는 두 곳에서 등록합니다.

| 화면 | 언제 |
|---|---|
| `KIS API 키 등록` | 이 PC 에 등록된 키가 없는 상태로 로그인했을 때 자동으로 나옵니다 |
| `설정` → `KIS Open API 연동` | 키를 추가, 수정, 삭제할 때 |

모의투자와 실전투자 키를 따로 등록하며 한쪽만 등록해도 됩니다. 입력하는 값은 `App Key`, `App Secret`,
`계좌번호` 이고 `설정` 화면에서는 `HTS ID (선택)` 도 넣을 수 있습니다. HTS ID 를 넣으면 체결 통보를
실시간으로 받고 비워 두면 `체결 내역` 화면을 열거나 새로고침할 때만 체결 여부를 확인합니다.

## 모의와 실전 전환

`설정` → `KIS Open API 연동` 의 `모의 투자 모드` 토글로 전환합니다. 모의와 실전 키가 모두 등록되어 있어야
토글을 쓸 수 있습니다.

| 환경 | 화면 설명 |
|---|---|
| 모의 | `모의 환경 (openapivts) — 가상 자금으로 주문 시뮬레이션` |
| 실전 | `실전 환경 (openapi) — 실계좌로 주문 체결` |

전환하면 액세스 토큰이 다시 발급됩니다. 실전 환경에서는 실제 계좌로 주문이 체결됩니다.

## 주문

Trading Room 하단의 주문 바에서 주문합니다.

<!-- 스크린샷: Trading Room 하단 주문 바 (BUY/SELL, 수량, 예상 체결액, 예수금, 즉시 체결, 주문 버튼) -->

1. `▲ BUY` 또는 `▼ SELL` 을 고릅니다.
2. `수량` 을 입력합니다. 옆의 `MAX` 를 누르면 예수금으로 살 수 있는 최대 수량이 들어갑니다.
3. 가격 방식을 고릅니다. `즉시 체결` 을 누르면 `지정가` 로 바뀌고 가격 입력칸이 나옵니다.
4. `▲ BUY 주문` 또는 `▼ SELL 주문` 을 누릅니다.

주문 바에는 `예상 체결액` 과 `예수금` 이 함께 표시됩니다.

KIS 해외주식 주문에는 시장가가 없어서 `즉시 체결` 은 현재가에서 1% 불리한 쪽(매수는 위, 매도는 아래)의
지정가로 주문합니다. 예상 체결액도 이 가격을 기준으로 계산합니다.

## 체결 확인

주문 직후에는 Trading Room 가운데 열의 `보유 · 주문` 패널에서 확인합니다.

| 영역 | 내용 |
|---|---|
| 보유 | 이 종목의 `보유` 수량, `평단`, `평가손익` |
| `이번 세션 주문` | 이 화면에서 낸 주문. 상태는 `접수`, `체결`, `실패` 로 표시됩니다 |

`접수` 는 지정가 주문이 체결을 기다리는 상태입니다. 이 화면에서는 이후 체결을 실시간으로 반영하지 않으므로
최종 결과는 왼쪽 메뉴의 `체결 내역` 에서 확인합니다.

`체결 내역` 화면은 열 때와 `새로고침` 을 누를 때 접수 상태 주문을 KIS 에 다시 조회해 상태를 맞춥니다.
`전체`, `BUY`, `SELL`, `실패만` 과 기간, 종목으로 거를 수 있고 `CSV 내보내기` 로 내려받을 수 있습니다.

## 키 보관

- App Key, App Secret, 계좌번호, HTS ID, 액세스 토큰은 Windows 자격 증명 저장소에 `EarningWhisperer`
  이름으로 저장됩니다. 앱은 키를 평문 파일로 남기지 않습니다.
- 주문은 앱이 KIS 서버로 직접 보냅니다. EarningWhisperer 서버는 KIS 를 호출하지 않으며 주문이 끝난 뒤
  주문 기록과 잔고만 받아 저장합니다.
- `설정` 화면의 키 카드에는 App Key 와 계좌번호를 가린 형태로 표시하고 App Secret 은 표시하지 않습니다.
  수정할 때 빈칸으로 둔 항목은 기존 값을 그대로 씁니다. HTS ID 는 기존 값이 미리 채워져 있어 지우면 삭제됩니다.
- 화면 하단 상태 표시줄의 `KIS` 항목에서 토큰 상태를 `유효`, `만료`, `미연결` 로 볼 수 있습니다. 만료되었으면
  `설정` 의 `토큰 재발급` 을 누릅니다.
