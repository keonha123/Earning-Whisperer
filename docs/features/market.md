# 홈과 종목

로그인 후 처음 보이는 `홈` 과 종목을 찾는 화면, 어느 화면에서나 여는 종목 브리핑을 설명합니다. 실적 일정,
계좌 요약, 종목 정보를 어디서 보는지 다루며 앱 사용자를 위한 문서입니다.

## 홈

왼쪽 메뉴의 `홈` 입니다. 왼쪽 넓은 열에 어닝콜, 오른쪽 좁은 열에 계좌와 시장 요약이 있습니다.

<!-- 스크린샷: 홈 전체 (진행 중인 콜, 내 종목의 다가오는 콜, 전체 일정, 계좌, 시장) -->

| 영역 | 내용 |
|---|---|
| `시연 재생` | 오른쪽 위. 시연 종목(WMT)의 콜 화면을 열고 재생을 시작합니다 |
| 진행 중인 콜 | 예정 시각 기준으로 진행 중인 콜이 있을 때만 보입니다. `콜 화면 열기` 로 들어갑니다 |
| `내 종목의 다가오는 콜` | 관심 · 보유 종목의 예정된 실적 콜(한국 시간). 행을 누르면 종목 브리핑이 열립니다 |
| `전체 일정` | 오늘 · 내일 · 이번 주 · 다음 주 묶음의 실적 콜 일정 |
| `지난 콜` | 아직 준비 중입니다 |
| `계좌` | 계좌 종류, 총자산, 오늘 손익, 주문 가능 금액, 보유 종목 수. `포트폴리오에서 자세히` 로 넘어갑니다 |
| `시장` | 시장 지수와 등락 |

시장 지수는 원지수가 아니라 ETF 가격입니다. 원지수 시세는 유료 데이터여서 ETF 로 대신합니다.
홈을 열 때 KIS 잔고를 한 번 불러옵니다. 불러오지 못하면 마지막 값 옆에 `동기화 실패` 와 `다시 시도` 가 보입니다.
자산 현황, 자산 추이, 보유 종목 표는 `포트폴리오` 의 `자산 · 보유` 탭에서 봅니다.

## 종목

왼쪽 메뉴의 `종목` 입니다. S&P 500 종목을 시가총액 순으로 보여 주고, 관심 · 보유 · 이번 주 콜 필터와 검색으로
종목을 찾습니다. 화면 구성은 [종목 화면 명세](../design/screens/stocks.md)에 있습니다.

<!-- 스크린샷: 종목 화면 (필터, 검색칸, 종목 표) -->

| 열 | 내용 |
|---|---|
| `티커`, `회사명`, `섹터` | 종목 기본 정보. `섹터` 는 창이 넓을 때만 보입니다 |
| `시가총액` | 시가총액 |
| `현재가`, `일일` | 현재가와 하루 등락률 |

- 회사명 옆에 관심 종목은 별, 보유 종목은 `보유`, 이번 주 실적 콜이 있는 종목은 `콜 10/8 (목)` 처럼 날짜가 붙습니다.
- `전체` · `관심` · `보유` · `이번 주 콜` 필터로 목록을 거릅니다. 검색은 고른 필터 안에서 티커와 회사명을 찾습니다.
- 한 페이지에 50개씩 보이며 아래쪽에서 페이지를 넘깁니다.
- 행을 누르면 오른쪽에 종목 브리핑이 열립니다. 콜 화면은 브리핑의 `콜 화면 열기` 로 들어갑니다.
- 목록을 불러오지 못하면 실패 사유와 `다시 시도` 를 보여 줍니다.

시연은 홈의 시연 재생으로 시작합니다([빠른 시작](../overview/quick-start.md)).

## 종목 브리핑

홈이나 종목 화면에서 종목 행을 누르거나, 콜 화면 위쪽의 종목 정보를 누르면 오른쪽에서 종목 브리핑이 열립니다.

| 영역 | 내용 |
|---|---|
| `다음 콜` | 콜까지 남은 시간, 일정(한국 시간과 미 동부 시간, `확정` · `예정`), `EPS 컨센서스`, `매출 컨센서스` |
| `최근 어닝 반응` | 지난 분기별 EPS 예상 → 실제와 발표일 주가 반응 |
| `30일 종가` | 최근 30일 종가 그래프와 기간 · 마지막 거래일 등락 |
| `기본 정보` | `섹터`, `시가총액`, `52주 고가`, `52주 저가`, `배당수익률` |
| `AI 요약` | 아직 준비 중입니다 |

창 아래의 `관심 추가` / `관심 해제` 로 관심종목을 관리하고 `콜 화면 열기` 로 그 종목의 콜 화면에 들어갑니다.

## 한계

- 어닝 분석은 S&P 500 종목만 지원합니다. 그 밖의 종목은 종목 브리핑에 `지원 외` 가 표시됩니다.
- 데이터가 아직 들어오지 않은 항목은 `기본 정보를 아직 받지 못했습니다.` 처럼 빈 상태 문구로 표시됩니다.
- 홈의 계좌 요약은 등록한 KIS 계좌의 잔고를 기준으로 하며 잔고를 한 번도 불러오지 못하면 비어 있습니다.
- Trading Room 의 가격 차트는 30일 일봉 종가를 쓰며 분봉 실시간 차트는 아직 없습니다.
