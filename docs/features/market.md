# 대시보드와 마켓

로그인 후 처음 보이는 `대시보드` 와 종목을 찾는 `Market` 화면을 설명합니다. 지수, 계좌 요약, 실적 일정,
종목 상세를 어디서 보는지 다루며 앱 사용자를 위한 문서입니다.

## 대시보드

왼쪽 메뉴의 `대시보드` 입니다. 위에서부터 다음 순서로 배치되어 있습니다.

<!-- 스크린샷: 대시보드 전체 (지수 띠, 자산 카드, 자산 추이, 보유종목, 다음 어닝콜) -->

| 영역 | 내용 |
|---|---|
| 머리 | `마지막 동기화` 시각과 `동기화` 버튼. 누르면 KIS 잔고를 다시 불러옵니다 |
| 지수 띠 | 미국 시장 대표 ETF 5종(SPY, QQQ, DIA, IWM, VIXY)의 가격과 등락 |
| 자산 카드 | `총 자산 (USD)`, `현금`, `평가`, `주문가능` 금액과 손익 |
| `자산 추이` | 기록된 자산 스냅샷을 선 그래프로 표시합니다. `7D`, `30D`, `90D` 로 기간을 바꿉니다 |
| 보유·관심 표 | `보유종목`, `관심종목` 탭. 행을 누르면 종목 상세가 열립니다 |
| `다음 어닝콜` | 예정된 실적 발표 일정(한국 시간 기준). 행을 누르면 종목 상세가 열리고 진행 중인 콜이 있으면 `입장 →` 으로 Trading Room 에 들어갑니다 |

지수 띠는 원지수가 아니라 ETF 가격입니다. 원지수 시세는 유료 데이터여서 ETF 로 대신합니다.

## Market

왼쪽 메뉴의 `Market` 입니다. 화면 제목은 `S&P 500 Market` 이고 종목을 시가총액 순으로 보여 줍니다.

<!-- 스크린샷: Market 화면 (검색칸, 종목 표, 진입 버튼) -->

| 열 | 내용 |
|---|---|
| `티커`, `회사명`, `섹터` | 종목 기본 정보. `섹터` 는 창이 넓을 때만 보입니다 |
| `시가총액` | 시가총액 |
| `현재가`, `일일%` | 현재가와 하루 등락률 |
| `진입` | 그 종목의 Trading Room 으로 이동합니다 |

- `티커 또는 회사명 검색...` 칸에 입력하면 목록을 거릅니다.
- 한 페이지에 50개씩 보이며 아래쪽에서 페이지를 넘깁니다.

시연 어닝콜은 이 화면에서 `WMT` 를 찾아 `진입` 한 뒤 재생합니다([빠른 시작](../overview/quick-start.md)).

## 종목 상세

대시보드의 표나 `다음 어닝콜` 에서 종목을 누르거나, Trading Room 상단의 `종목 정보` 를 누르면 오른쪽에서
종목 상세 창이 열립니다.

| 영역 | 내용 |
|---|---|
| `다음 어닝` | 다음 실적 발표 일정과 `EPS 컨센서스`, `매출 컨센서스`. 일정이 `확정` 인지 `미확정` 인지 표시합니다 |
| `기본 정보` | `섹터`, `시가총액`, `52주 고가`, `52주 저가`, `배당수익률` |
| `30일 일봉` | 최근 30일 종가 그래프와 기간 등락 |
| `최근 어닝 반응` | 지난 분기별 `EPS 예상`, `EPS 실제` 와 발표 당일 주가 반응 |
| `AI 분석 요약` | 아직 연결되지 않아 `AI 분석 데이터 준비 중입니다.` 만 표시됩니다 |

창 아래의 `관심종목 추가` / `관심종목 제거` 로 관심종목을 관리하고 `TradingRoom 진입` 으로 Trading Room 에
들어갑니다.

<!-- 스크린샷: 종목 상세 창 (WMT) -->

## 한계

- 어닝 분석은 S&P 500 종목만 지원합니다. 그 밖의 종목은 상세 창에 `지원 외` 가 표시됩니다.
- 데이터가 아직 들어오지 않은 항목은 `기본 정보가 아직 동기화되지 않았습니다.` 처럼 빈 상태 문구로 표시됩니다.
- 자산 카드와 보유종목은 등록한 KIS 계좌의 잔고를 기준으로 하며 잔고를 불러오지 못하면 비어 있습니다.
- Trading Room 의 가격 차트는 30일 일봉 종가를 쓰며 분봉 실시간 차트는 아직 없습니다.
