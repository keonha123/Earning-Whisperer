# 종합 판단

어닝콜이 끝난 뒤 콜 화면에 나타나는 종합 판단을 설명합니다. 각 항목이 무엇을 뜻하는지와 값이 비어 있을 때
어떻게 읽어야 하는지를 다루며, 앱 사용자와 시연을 보는 평가자를 위한 문서입니다.

## 화면 위치

콜이 끝나면 콜 화면 배치가 바뀌어 오른쪽 넓은 자리에 종합 판단이 나옵니다. 위쪽 `판단` / `질문` 전환에서
`판단` 이 기본으로 골라져 있고(콜 진행 중에 `이 대목 질문` 을 눌렀으면 `질문`), 왼쪽에는 좁은 `자막 다시 보기` 가 남습니다.

판단이 도착하기 전에는 `콜 전체를 종합하는 중입니다` 와 `콜이 끝나면 전문을 다시 읽고 판단을 만듭니다.` 가
표시됩니다. 시연을 `중지` 로 멈췄으면 판단을 만들지 않고 `시연을 중지했습니다` 가 표시됩니다.

## 동작 방식

콜이 끝나면 서버가 전체 발언을 AI 엔진에 보내 판단을 받고, 이어서 질문 회피, 관련 종목 영향, 손절·익절 계획을
따로 받아 한 번에 화면으로 보냅니다. 종합 판단은 재생 한 번에 한 건만 만들어집니다.

## 실행 판단

판단의 첫 줄은 `실행 판단` 입니다. "이 판단대로 움직여도 되는가" 에 대한 답이며, 권고 행동과 실행 조건 검사
결과가 `·` 로 이어져 큰 글씨로 표시됩니다(예: `실행 보류 · 조건부 보류`).

| 항목 | 값 |
|---|---|
| 권고 행동 | `진입 가능`, `관찰`, `관망`, `청산 우선`, `실행 보류` |
| 실행 조건 검사 결과 | `통과`, `조건부 보류`, `차단` |

방향과는 별개이므로 `강세` 판단에 `실행 보류` 가 붙는 것도 정상입니다. 뉴스 근거가 없으면 이런 조합이 나옵니다.
그 아래에 포지션 의도와 `보류 사유 · …` 가 값이 있을 때만 표시됩니다. 실행 판단이 오지 않았으면
`실행 판단이 오지 않았습니다 · 방향만 참고하세요` 가 표시됩니다.

## 방향

실행 판단 아래 줄에 판단의 근거가 되는 방향이 표시됩니다.

| 항목 | 설명 |
|---|---|
| `방향` | `강세`, `약세`, `중립` 중 하나. 색 없이 글자로만 표시합니다 |
| 촉매 유형 | 방향 아래 작은 글씨. 예: `가이던스 상향`, `실적 성장`, `마진 개선` |
| `강도`, `신뢰도` | 방향이 얼마나 강한지, 판단을 얼마나 확신하는지를 막대와 백분율로 표시합니다. 값이 없으면 빗금 막대와 `—` 로 표시합니다 |
| `기관 등급` | 오른쪽의 A~E 등급과 점수 |

## 펼쳐 보는 항목

나머지 정보는 눌러서 펼치는 항목으로 나옵니다. 값이 없는 항목은 나오지 않습니다.

| 항목 | 오른쪽 표시 | 내용 |
|---|---|---|
| `판단 근거` | `영어 원문` | AI 엔진이 영어로 쓴 판단 근거 |
| `반대 논거 · 리스크` | 항목 수 | 판단과 반대되는 논거와 리스크 목록 |
| `질문 회피` | `회피도 N%` | 아래 설명 |
| `파급 영향` | `N개 종목` | 아래 설명 |
| `손절 · 익절 계획` | `참고용` | 아래 설명 |

### 질문 회피

Q&A 에서 경영진이 애널리스트 질문을 얼마나 피했는지 보여 줍니다.

- `회피도`: 막대가 길수록 질문을 피했다는 뜻입니다.
- `답변에서 빠진 주제 · …`: 질문에는 있었지만 답변에서 다루지 않은 주제
- `답변이 다른 주제로 전환되었습니다.`: 답변이 질문과 다른 주제로 넘어간 경우에만 표시됩니다.
- 마지막에 그렇게 본 이유가 한국어로 적힙니다.

### 파급 영향

이 콜이 관련 종목에 줄 영향을 종목마다 한 줄로 보여 줍니다. 시연에서는 TGT, COST, AMZN 이 대상입니다.

- 티커: 누르면 그 종목의 종목 브리핑이 열립니다.
- 관계: 공급망, 경쟁 같은 관계
- 방향: `수혜`, `부정`, `혼재`, `중립`
- 점수: 영향의 크기(%). 영향을 잴 근거가 없었으면 `근거 없음` 으로 표시합니다. 영향이 0 이라는 뜻이 아닙니다.
- 근거 문장: 길면 잘리고, 마우스를 올리면 전체가 보입니다.

### 손절 · 익절 계획

| 항목 | 설명 |
|---|---|
| 방향과 기준가 | `LONG` 또는 `SHORT` 와 `기준가 $xx.xx` |
| `손절`, `1차 익절`, `2차 익절` | 가격과 기준가 대비 변동률 |
| `손익비` | 1차 익절 기준 손익비 |
| `시간 손절 N일` | 가격이 아니라 보유 기간으로 정한 손절 기준. 값이 있을 때만 표시됩니다 |
| `무효화 조건 · …` | 계획이 더는 맞지 않게 되는 조건. 값이 있을 때만 표시됩니다 |

가격 정보가 없거나 방향이 서지 않으면 숫자 대신 `가격 정보가 없어 계획을 산출하지 못했습니다.` 같은 사유가
표시됩니다. 계획은 참고 정보이며 주문 입력과 연결되어 있지 않습니다.

## 경고와 부가 정보 누락

- `!` 로 시작하는 경고색 목록은 AI 엔진이 붙인 주의사항을 그대로 보여 줍니다. 판단이 근거 없이 나왔는지 확인하는
  단서입니다.
- `회피 지표 · 파급 영향 · 손절 계획을 가져오지 못했습니다. 판단만 표시합니다.` 가 나오면 판단 외 정보를
  받지 못한 상태입니다.
- 맨 아래에는 판단에 쓰인 모델 이름과 생성 시각(KST)이 표시됩니다.
- 그 아래에 직전 콜 대조가 있었으면 `직전 콜 대조 · <비교 대상>` 과 변화 유형별 개수가 표시됩니다
  ([직전 콜 대조](transcript-diff.md)).

## 한계

- 서버에서 판단 생성이 실패하면 결과가 오지 않습니다. 콜이 끝나고 3분이 지나면 `종합 판단을 받지 못했습니다` 로
  바뀝니다. 판단은 재생 한 번에 한 건만 오므로 다시 받으려면 콜 바의 `처음부터` 로 다시 재생해야 합니다. 판단
  재요청은 준비 중입니다.
- 질문 회피는 시연 스크립트에 들어 있는 질문·답변 2쌍만으로 계산합니다.
