# 어닝콜 자막

Trading Room 의 `실시간 스크립트` 패널이 어닝콜 발언을 어떻게 보여 주는지 설명합니다. 앱 사용자와 시연을
보는 평가자를 위한 문서입니다.

## 화면 위치

`Market` 또는 `대시보드` 에서 종목의 Trading Room 에 들어가면 왼쪽 열에 `실시간 스크립트` 패널이 있습니다.
시연에서는 월마트(WMT) Trading Room 에서 상단의 `시연 시작` 을 누르면 자막이 들어오기 시작합니다.

## 보이는 정보

각 줄은 아래 형식으로 표시됩니다.

```
[00:30] · CEO · John Furner
Our core retail business had another strong quarter ...
```

| 요소 | 설명 |
|---|---|
| `[mm:ss]` | 스크립트에 적힌 문장 시작 시각. 시연 스크립트는 문장마다 15초 간격으로 매겨져 있어 실제 콜 시각이나 재생 간격(6초)과 다릅니다 |
| 발화자 | 직책과 이름. 밑줄이 있으면 눌러서 `발화자 프로필` 을 엽니다 |
| 본문 | 발언 원문. 시연 데이터는 영어 원문을 그대로 보여 줍니다 |

- 가장 최근 줄은 배경이 밝게 강조됩니다.
- 위로 스크롤해 지난 발언을 읽는 동안에는 화면이 자동으로 내려가지 않습니다. `최신 ↓` 을 누르면 맨 아래로
  돌아갑니다.

패널 상단 오른쪽에는 상태가 표시됩니다.

| 표시 | 의미 |
|---|---|
| `대기 중` | 아직 받은 발언이 없습니다. 본문에는 `진행 중인 어닝콜이 없습니다.` 가 나옵니다 |
| `LIVE` | 콜이 진행 중입니다 |
| `어닝콜 종료` | 콜이 끝났습니다. 받은 발언은 지워지지 않고 그대로 남습니다 |

## 발화자 프로필

Trading Room 상단의 `발화자` 버튼이나 자막의 발화자 이름을 누르면 `발화자 프로필` 창이 열립니다.
참가자는 경영진과 애널리스트로 나뉘어 표시됩니다. 이름, 직책, 소속처럼 트랜스크립트에 적힌 정보와,
이번 재생에서 실제로 도착한 발언 수와 팩트체크 판정을 집계해 보여 줍니다. 화법 성향처럼 원문에서 확인할 수
없는 값은 표시하지 않습니다.

## 시연 데이터

| 항목 | 값 |
|---|---|
| 콜 | 월마트(WMT) 2026-08-20 어닝콜 발췌 |
| 문장 수 | 24 |
| 길이 | 기본 설정에서 약 2분 30초 (문장 간격 6초) |

발췌 문장은 실제 트랜스크립트 원문이며 지어낸 문장은 없습니다.

## 한계

- 이 문서는 시연 재생만 다룹니다. 시연에서 보이는 자막은 서버가 준비된 스크립트를 실제 콜과 같은 경로로
  흘려보낸 것이며 진행 중인 콜의 음성을 받아 적는 경로는 다루지 않습니다.
- 자막은 번역하지 않습니다.
- 세션 라벨, 경과 시간, 말하기 속도(WPM)는 아직 화면에 표시하지 않습니다.
- `시연 시작` 은 지금 열어 둔 종목으로 월마트 스크립트를 재생합니다. 다른 종목에서 누르면 자막은 나오지만
  팩트체크 근거가 맞지 않습니다.
