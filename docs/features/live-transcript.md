# 어닝콜 자막

콜 화면의 `자막` 이 어닝콜 발언을 어떻게 보여 주는지 설명합니다. 앱 사용자와 시연을
보는 평가자를 위한 문서입니다.

## 화면 위치

종목 브리핑의 `콜 화면 열기` 나 홈의 진행 중인 콜로 콜 화면에 들어가면 자막이 보입니다.
시연에서는 월마트(WMT) 콜 화면의 콜 바에서 `시연 재생` 을 누르면 자막이 들어오기 시작합니다.

콜이 시작되기 전에는 자막 자리에 브리핑(`콜 시작까지`, `시장 기대치`, `최근 어닝 반응`)이 보이고, 첫 발언이 오면
자막으로 바뀝니다. 콜이 진행되는 동안 자막은 넓은 자리를 쓰고, 콜이 끝나면 왼쪽 좁은 `자막 다시 보기` 로 옮겨
갑니다. 받은 발언은 지워지지 않고 그대로 남습니다.

## 보이는 정보

각 줄은 아래 형식으로 표시됩니다.

```
00:30  CEO · John Furner
Our core retail business had another strong quarter ...
```

| 요소 | 설명 |
|---|---|
| `mm:ss` | 스크립트에 적힌 문장 시작 시각. 시연 스크립트는 문장마다 15초 간격으로 매겨져 있어 실제 콜 시각이나 재생 간격(6초)과 다릅니다 |
| 발화자 | 트랜스크립트에 적힌 발화자 표기. 시연 데이터는 직책과 이름입니다. 점선 밑줄을 누르면 `발화자 프로필` 을 엽니다 |
| 본문 | 발언 원문. 시연 데이터는 영어 원문을 그대로 보여 줍니다 |

- 가장 최근 발언은 글자가 조금 더 밝게 표시됩니다.
- 위로 스크롤해 지난 발언을 읽는 동안에는 화면이 자동으로 내려가지 않습니다. 그동안 들어온 발언 수가
  `새 발언 N개 ↓` 로 표시되고, 누르면 맨 아래로 돌아갑니다.
- 자막 머리에는 받은 문장 수가 `N문장` 으로 표시됩니다.
- 발언 줄에 마우스를 올리면 `이 대목 질문` 이 나옵니다. 누르면 그 발언을 범위로 질문할 수 있습니다
  ([어닝콜 질의응답](assistant.md)).
- 발언 아래에는 직전 콜과 비교한 대조 칩이나 카드가 붙을 수 있습니다([직전 콜 대조](transcript-diff.md)).

콜 상태는 화면 위쪽 콜 바에 표시됩니다.

| 표시 | 의미 |
|---|---|
| `시작 전` | 콜이 아직 시작되지 않았습니다 |
| `LIVE` | 첫 발언이 도착해 콜이 진행 중입니다. 콜 바에 `N 경과` 도 표시됩니다 |
| `종료` | 콜이 끝났습니다. 원문 · 번역 전환은 콜 진행 중에만 있습니다 |

이 화면에서 `시연 재생` 이나 `처음부터` 로 재생을 시작했으면 콜 바에 `시연` 표시가 붙습니다.

## 번역과 용어 설명

자막 위쪽의 `원문 / 원문 + 번역` 전환으로 한국어 번역을 켜고 끕니다. 처음에는 번역이 켜져 있습니다.

- 번역은 원문 몇 문장을 묶어 만들기 때문에 원문보다 몇 초 늦게, 묶음의 마지막 문장 아래에 `번역` 으로 붙습니다.
- 번역문 안의 어려운 전문용어(기존점 매출, 가이던스 등)에는 점선 밑줄이 있습니다. 밑줄은 같은 용어가 문단에서
  처음 나온 곳에만 긋고, 한 문단에 5개까지입니다.
- 밑줄을 누르면 번역어와 원문 용어, 그 용어를 쉽게 풀어 쓴 설명이 나옵니다. 설명은 용어의 뜻에 이어 어닝콜에서
  그 용어가 무엇을 알려 주는지 덧붙입니다. Esc 나 바깥을 누르면 닫힙니다.
- 번역에 실패하거나 너무 늦어진 묶음은 번역 없이 원문만 남습니다. 용어 사전을 받지 못하면 밑줄 없이 번역만
  보입니다. 시연을 처음부터 다시 재생하면 앞 회차의 번역은 늦게 도착해도 보이지 않습니다.
- 용어 사전에는 업종을 가리지 않고 어닝콜에서 자주 나오는 공통 용어 232개가 있습니다. 은행의 순이자마진,
  에너지의 생산 단가 같은 업종 전용어는 아직 밑줄이 없습니다. 용어를 고른 방법은
  [`backend/tools/glossary-mining/README.md`](../../backend/tools/glossary-mining/README.md)에 있습니다.
- 뜻이 여럿인 단어(예: 인수합병을 말하는 `transactions`)는 문맥과 다른 설명이 나올 수 있습니다.

## 발화자 프로필

콜 바의 `발화자` 버튼(옆에 참가자 수)이나 자막의 발화자 이름을 누르면 `발화자 프로필` 창이 열립니다.
참가자는 경영진과 애널리스트로 나뉘어 표시됩니다. 이름, 직책, 소속처럼 트랜스크립트에 적힌 정보와,
이번 재생에서 실제로 도착한 발언을 집계한 `발언`, `단어`, `구간` 을 보여 줍니다. 화법 성향처럼 원문에서 확인할 수
없는 값은 표시하지 않습니다.

## 시연 데이터

| 항목 | 값 |
|---|---|
| 콜 | 월마트(WMT) 2026-08-20 어닝콜 발췌 |
| 문장 수 | 24 |
| 길이 | 기본 설정에서 약 2분 30초 (문장 간격 6초) |

발췌 문장은 실제 트랜스크립트 원문이며 지어낸 문장은 없습니다.

## 한계

- 이 문서는 시연 재생만 다룹니다. 시연에서 보이는 자막은 서버가 준비된 스크립트를 실제 콜과 같은 경로로
  흘려보낸 것이며 진행 중인 콜의 음성을 받아 적는 경로는 다루지 않습니다.
- 세션 라벨과 말하기 속도(WPM)는 아직 화면에 표시하지 않습니다.
