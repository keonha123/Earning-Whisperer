# 0004. 시연은 backend 가 과거 실제 어닝콜을 재생하는 방식으로 합니다

- 날짜: 2026-09-09
- 상태: 채택
- 결정한 사람: @keonha123
- 대체한 ADR: 없음
- 대체된 ADR: 없음

## 배경

2026-09-09 이전의 어닝콜 시연은 트레이딩 터미널 렌더러가 목업 데이터를 타이머로 뿌리는 방식이었습니다.
`useEarningsDemoPlayback` 훅이 Oracle 콜을 요약·번안한 스크립트를 재생했고, 팩트체크·종합 평가 같은 화면도
목업 값을 그렸습니다(커밋 `b2d5e13`, `7163fad`. 개발 빌드에서만 표시). 이 구조에서는 backend 와 ai-engine 이 실제로 동작하는지 시연에서 보여줄
수 없었습니다.

[시연 자료](../demo/README.md)는 목업을 걷어낸 이유로, 프론트가 가짜 데이터를 그리는 코드가 남아 있으면
실연동을 덮어버린다는 점을 적고 있습니다.

## 결정

backend 가 준비된 어닝콜 스크립트를 실제 인입 경로로 재생합니다(커밋 `2ecbf46`).

- 터미널의 "시연 시작" 버튼이 `POST /api/v1/demo/earnings-call/start` 를 호출합니다. `stop`, `status`,
  `speakers` 엔드포인트가 함께 있습니다.
- `DemoEarningsCallService` 가 스크립트(`backend/src/main/resources/data/demo-earnings-call.json`)의 세그먼트를 간격마다
  `TranscriptService` 검증을 거쳐 `/topic/transcript/{ticker}` 로 발행하고, 같은 문장을 ai-engine 팩트체크로
  보냅니다([ADR 0003](0003-fact-check-with-evidence-retrieval-and-llm.md)). Data Pipeline 의 STT 단계를 사전
  녹취록으로 대체합니다. 현재 STT 인입 경로(`TranscriptService`)는 자막만 발행하므로, 팩트체크·종합 판단 호출은
  재생 경로에만 연결되어 있습니다.
- 재생은 API 로 시작해 1회 재생 후 끝나고 도중에 중지할 수 있습니다.
- 재생 대상은 월마트 FY2027 Q2 어닝콜(2026-08-20)의 실제 트랜스크립트 발췌입니다(커밋 `2c64563`). 준비 발언
  24문장과 애널리스트 질의응답 한 쌍이 들어 있고 지어낸 문장은 없습니다. 원본은
  `data_pipeline/data/demo/wmt-2026q2-transcript.json` 입니다.
- 세그먼트 타임스탬프는 재생 시각이 아니라 스크립트의 `call_started_at` 기준으로 찍습니다(커밋 `af2b987`).
  ai-engine 이 이 값을 기준으로 근거 검색 창(과거 30일)을 잡기 때문입니다.

월마트 콜을 고른 이유는 커밋 `51c6d58` 에 있습니다. 콜 당일 보도에 경영진 어법과 시장 해석의 괴리가 기록되어
있었습니다. CFO 는 "our business is strong, it was a good quarter" 라고 했고, 같은 날 "Walmart Tumbles As Weak
U.S. Sales Spark Spending Concerns" 기사가 나왔습니다. 실적은 예상을 넘었는데 주가는 떨어진 콜입니다. 커밋
메시지는 "시스템이 아무것도 잡아내지 못하면 이 제품이 왜 필요한지 보여줄 수 없다" 고 적었습니다.

## 검토한 대안

### 렌더러 목업 재생 유지

배경에 적은 이유로 걷어냈습니다. 목업 파일은 `docs/demo/fixtures/` 로 옮겨 참고 자료로 남겼습니다
(커밋 `b57d27c`).

### 기존 `DemoReplayService` 재사용

backend 에는 2026-04-02 에 만든 `DemoReplayService` 가 있습니다. 서버 기동 시 자동으로 시작해 `/topic/live/demo`
로 스크립트를 무한 반복하는 웹 쇼케이스용입니다. 커밋 `2ecbf46` 은 새 재생을 이와 별개로 두고 차이를 "API 로
시작하고 1회 재생 후 스스로 끝나며 중지할 수 있다" 로 적었습니다. 기존 서비스를 확장하지 않은 이유는 그 외에
기록이 없습니다.

### 실제 진행 중인 어닝콜을 실시간으로 받기

Data Pipeline 에는 어닝콜 웹캐스트를 STT 로 받는 경로가 있습니다(커밋 `f80343f`). 시연에서 이 경로 대신 재생을
고른 이유는 기록이 없습니다.

### 근거 검색 창을 늘리기

과거 콜을 재생 시각 기준으로 찍으면 그 콜 시점의 뉴스가 검색 창 밖으로 밀려 모든 판정이 근거 부족이 됩니다.
창을 늘리는 방법은 무관한 최신 뉴스까지 딸려 오므로 고르지 않고 기준 시각을 콜 시각으로 바꿨습니다
(커밋 `af2b987`).

## 결과

좋아진 점

- 시연 화면의 트랜스크립트와 팩트체크가 실제 backend·ai-engine 경로를 거친 결과가 되었습니다.
- 근거 뉴스와 트랜스크립트 스냅샷을 저장소(`data_pipeline/data/demo/`)에 두어 같은 시연을 다시 돌릴 수 있고
  어떤 근거로 판정이 나왔는지 열어 볼 수 있습니다(커밋 `51c6d58`).

감수한 비용

- STT 단계는 시연에 포함되지 않습니다.
- 시연 전에 근거 뉴스를 ai-engine 에 적재해야 합니다. 적재하지 않으면 판정이 모두 근거 부족으로 나오므로,
  backend 는 재생 시작 응답에 `evidence_warning` 을 싣습니다(커밋 `af2b987`).
- 근거 적재에 쓰는 Gemini 임베딩은 무료 등급에서 하루 1,000요청 제한이 있어 적재를 반복하면 그날 할당량을
  소진합니다(커밋 `1aaef15`).
- 근거 수집 창을 [콜일 -30일, 콜일 +1일] 로 잡아 콜 당일 실적 보도가 근거에 들어갑니다. 이 때문에 검증이
  부분적으로 순환합니다([시연 자료](../demo/README.md) "남아 있는 한계").

후속 조치

- 직전 콜 발언 대조에 쓰도록 월마트 직전 콜(Q1 FY2027, 2026-05-21) 트랜스크립트를 추가했습니다
  (커밋 `591a98c`).
