# 빠른 시작

EarningWhisperer Terminal 을 처음 설치한 사용자가 로그인하고 시연용 어닝콜을 한 번 재생해 보기까지의
과정을 설명합니다. 개발 환경 구성은 이 문서에서 다루지 않습니다.

## 준비물

- Windows x64 PC. 현재 배포 중인 설치 파일은 Windows 용뿐입니다.
- 인터넷 연결. 앱은 시연 서버 `https://api.logothea.com` 에 접속합니다.
- Google 또는 카카오 계정. 앱 안에는 회원가입 화면이 없어 처음 쓰는 사용자는 소셜 로그인으로 시작합니다.
- 한국투자증권(KIS) 모의투자 App Key, App Secret, 계좌번호. 첫 로그인 직후 등록 화면이 나오며 한 쌍 이상
  등록해야 다음 화면으로 넘어갑니다.

자세한 조건은 [요구사항](../install/requirements.md)에 정리했습니다.

## 1. 설치

GitHub 릴리스 페이지에서 `EarningWhisperer.Terminal.Setup.0.1.0.exe` 를 받아 실행합니다. 코드 서명이 없어
Windows SmartScreen 경고가 나오며 `추가 정보` → `실행` 을 누르면 설치가 진행됩니다. 절차는
[데스크톱 앱 설치](../install/desktop-app.md)에 있습니다.

## 2. 로그인

앱을 열면 로그인 화면이 나옵니다.

<!-- 스크린샷: 로그인 화면 (이메일·비밀번호 입력란, Google로 계속하기·카카오로 계속하기 버튼) -->

| 방법 | 화면에서 누르는 것 | 설명 |
|---|---|---|
| Google | `Google로 계속하기` | 기본 브라우저에서 Google 로그인 창이 열립니다. 처음이면 계정이 자동으로 만들어집니다 |
| 카카오 | `카카오로 계속하기` | Google 과 같은 방식입니다 |
| 이메일 | `이메일`, `비밀번호` 입력 후 `로그인` | 이미 가입된 이메일 계정만 쓸 수 있습니다 |

`웹사이트에서 가입하기 ↗` 링크는 아직 동작하지 않습니다. 새 계정은 Google 또는 카카오 로그인으로 만듭니다.

## 3. KIS API 키 등록

KIS 키가 등록되지 않은 PC 에서 처음 로그인하면 `KIS API 키 등록` 화면이 나옵니다. `KIS 모의투자` 카드에
`App Key`, `App Secret`, `계좌번호` 를 입력하고 `저장하고 시작` 을 누르면 대시보드로 이동합니다.
`KIS 실전투자` 카드는 비워 두어도 됩니다.

- 계좌번호는 숫자 8자리 또는 10자리(계좌 8자리 + 상품코드 2자리)입니다.
- 키는 서버로 보내지 않고 이 PC 의 Windows 자격 증명 저장소에 보관합니다.

키 발급과 관리는 [KIS 주문](../features/trading.md)을 참고합니다.

## 4. 시연 어닝콜 재생

시연 데이터는 월마트(WMT) 2026-08-20 어닝콜 발췌입니다.

1. 왼쪽 메뉴에서 `Market` 을 엽니다.
2. `티커 또는 회사명 검색...` 칸에 `WMT` 를 입력하고 해당 행의 `진입` 을 누릅니다. Trading Room 화면이 열립니다.
3. 상단의 `시연 시작` 을 누릅니다.

<!-- 스크린샷: Trading Room 상단 헤더 (WMT, 종목 정보, 시연 시작, 발화자 버튼) -->

재생은 서버에서 진행되며 문장 24개가 차례로 도착합니다. 기본 설정에서 전체 길이는 약 2분 30초입니다.
`시연 시작` 은 지금 열어 둔 종목으로 재생하므로 월마트가 아닌 종목에서 누르면 팩트체크 근거가 맞지 않습니다.

## 5. 화면에서 볼 것

Trading Room 은 세 열로 나뉩니다.

| 위치 | 패널 | 내용 | 자세히 |
|---|---|---|---|
| 왼쪽 | `실시간 스크립트` | 발언이 발화자, 시각과 함께 한 줄씩 쌓입니다 | [어닝콜 자막](../features/live-transcript.md) |
| 오른쪽 위 | `발언 검증` | 세 문장마다 사실 주장을 뉴스와 대조한 판정이 붙습니다 | [실시간 팩트체크](../features/fact-check.md) |
| 오른쪽 아래 | `어닝콜 종합 판단` | 콜이 끝난 뒤 방향, 등급, 질문 회피, 손절·익절 계획이 나옵니다 | [종합 판단](../features/earnings-summary.md) |
| 가운데 | 차트, `보유 · 주문`, 하단 주문 바 | 가격 차트와 KIS 모의투자 주문 | [KIS 주문](../features/trading.md) |

<!-- 스크린샷: 재생이 끝난 Trading Room 전체 (스크립트, 발언 검증, 종합 판단이 모두 보이는 상태) -->

팩트체크 판정은 문장이 나온 뒤 몇 초 늦게 붙습니다. 판정을 기다리는 동안 `AI 교차 분석 중...` 이 표시됩니다.
스크립트 패널 상단이 `어닝콜 종료` 로 바뀐 뒤 종합 판단이 도착할 때까지는
`어닝콜이 종료되었습니다. 전문을 종합 분석하는 중입니다...` 가 표시됩니다.

## 6. (선택) 모의투자 주문

Trading Room 하단 주문 바에서 `▲ BUY` 또는 `▼ SELL`, 수량을 고른 뒤 주문 버튼을 누르면 등록한 KIS 모의투자
계좌로 주문이 나갑니다. 주문 결과는 `보유 · 주문` 패널의 `이번 세션 주문` 과 왼쪽 메뉴의 `체결 내역` 에서
확인합니다. 시연 재생과 팩트체크는 주문 없이도 볼 수 있습니다.
