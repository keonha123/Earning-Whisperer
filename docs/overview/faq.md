# 자주 묻는 질문

Logothea 를 설치하거나 시연을 재생하면서 자주 나오는 질문과 답을 모았습니다.
앱 사용자와 시연을 보는 평가자를 위한 문서입니다.

## 설치와 접속

### Windows 에서 "Windows의 PC 보호" 경고가 나옵니다

설치 파일에 코드 서명이 없어 SmartScreen 경고가 나옵니다. `추가 정보` → `실행` 을 누르면 설치가 진행됩니다.
설치 파일이 릴리스와 같은지는 [데스크톱 앱 설치](../install/desktop-app.md)의 sha256 값으로 확인할 수 있습니다.

### macOS 에서 쓸 수 있나요?

현재 배포 중인 macOS 설치 파일은 없습니다. `v0.1.0-rc1` 은 Windows x64 용입니다.

### 로그인이 되지 않습니다

시연 서버는 비용 때문에 필요할 때만 켭니다. 브라우저에서 아래 주소를 열어 확인합니다.

```
https://api.logothea.com/actuator/health
```

`{"status":"UP"}` 이 나오면 서버가 켜져 있고, 오류 페이지가 나오거나 응답이 없으면 꺼진 상태입니다.

로그인에 실패하면 화면에는 원인과 관계없이 `이메일 또는 비밀번호가 올바르지 않습니다.` 가 표시되므로 함께 뜨는
알림으로 구분합니다. 서버가 꺼져 있으면 `서버가 응답하지 않습니다.`, PC 의 인터넷 연결이 끊겼으면
`네트워크 오류가 발생했습니다.` 로 시작하는 알림이 나옵니다.

### 회원가입은 어디서 하나요?

앱에는 회원가입 화면이 없습니다. `Google로 계속하기` 또는 `카카오로 계속하기` 로 처음 로그인하면 계정이
자동으로 만들어집니다. `웹사이트에서 가입` 링크는 아직 동작하지 않습니다(누르면 준비 중이라고 안내합니다).

### 소셜 로그인 중 "로컬 포트 9000 이 사용 중입니다" 가 나옵니다

소셜 로그인은 브라우저에서 받은 결과를 PC 의 9000번 포트로 넘겨받습니다. 다른 프로그램이 이 포트를 쓰고
있으면 로그인이 시작되지 않으므로, 그 프로그램을 끈 뒤 다시 시도합니다.

## 돈과 키

### 실제 돈이 오가나요?

`KIS 모의투자` 키만 등록했다면 한국투자증권 모의투자 계좌로 주문이 나가며 실제 돈은 오가지 않습니다.
`KIS 실전투자` 키로 시작했거나 `설정` 에서 실전 환경으로 전환했다면 실계좌로 주문이 체결되므로 주의가
필요합니다. 첫 등록 화면에서 실전 키만 넣으면 바로 실전 환경이 됩니다.
어닝콜 재생, 직전 콜 대조, 종합 판단, 질의응답은 주문을 내지 않습니다.

### KIS API 키는 어디에 저장되나요?

키는 이 PC 의 Windows 자격 증명 저장소에 저장되며 Logothea 서버로 보내지 않습니다. 주문도 앱이
한국투자증권 서버에 직접 보냅니다. `설정` 화면에서 키를 수정하거나 삭제할 수 있습니다.
자세한 내용은 [KIS 주문](../features/trading.md)에 있습니다.

### KIS 키 없이 시연만 볼 수 있나요?

볼 수 있습니다. 첫 로그인 직후 나오는 `주문용 KIS 키 등록` 화면에서 `나중에` 를 누르면 홈으로 넘어갑니다.
어닝콜 재생과 분석 기능은 KIS 와 상관없이 동작하고, 키는 주문할 때만 필요합니다.

## 시연

### 시연 재생을 눌렀는데 "이미 시연이 진행 중입니다" 가 나옵니다

시연 재생은 서버에서 종목마다 하나씩만 진행됩니다. 다른 사람이 같은 종목으로 먼저 재생을 시작했다면 그 재생이
끝날 때까지 새로 시작할 수 없습니다. 이때 같은 종목 화면을 열어 둔 사용자는 모두 같은 재생을 함께 봅니다.

### 시연 재생 직후 "근거 뉴스가 N건뿐입니다" 알림이 나옵니다

서버에 저장된 근거 뉴스가 적을 때 나오는 알림입니다. 알림 문구는 팩트체크를 말하지만, 뉴스 대조 팩트체크는
제품 범위에서 빠져 지금 화면에는 표시하지 않습니다. 재생은 그대로 진행됩니다.

### 콜이 끝났는데 종합 판단이 오지 않습니다

종합 판단은 콜이 끝난 뒤 한 번만 만들어집니다. 도착할 때까지 `콜 전체를 종합하는 중입니다` 가 표시되고, 3분이
지나도 오지 않으면 `종합 판단을 받지 못했습니다` 로 바뀝니다. 다시 받으려면 콜 바의 `처음부터` 로 시연을 다시
재생합니다. 판단 재요청은 준비 중입니다.

### 직전 분기와 비교한 내용은 어디서 보나요?

[직전 콜 대조](../features/transcript-diff.md)가 자막의 발언 아래, 콜 진행 중 옆 자리 `대조` 탭, 콜이 끝난 뒤
`판단` 아래에 표시됩니다.
