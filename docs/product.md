# 제품 정의

EarningWhisperer 가 무엇을 위한 제품이고 어디까지 만드는지 정리한 문서입니다. 기능을 더하거나 뺄지 정할 때
기준으로 삼으며, 팀원과 설계를 보려는 사람을 위한 문서입니다. 화면과 흐름은 [UX 문서](design/ux.md)에서,
기능별 사용법은 [기능 문서](features/)에서 다룹니다.

## 목표

미국 기업의 어닝콜을 한국 개인투자자가 실시간으로 이해하고, 지난 콜과 무엇이 달라졌는지 확인하고, 콜이 끝난
뒤 자기 포지션을 정할 수 있게 돕는 데스크톱 앱을 만듭니다.

EarningWhisperer 는 어닝콜 분석 도구입니다. 어닝콜 시청, 직전 콜 대조, 콜 종료 후 판단이 중심이고 주문과
자산 관리는 그 판단을 실행하는 보조 기능입니다.

## 대상 사용자

미국 주식에 투자하는 한국 개인투자자입니다.

- 미국 어닝콜은 한국 시간 밤이나 새벽에 영어로 진행됩니다. 실시간으로 다 듣기 어렵고 금융 용어가 장벽입니다.
- 기관처럼 유료 도구(AlphaSense, Bloomberg)를 쓰지 않습니다.
- 원하는 것은 경영진 말을 이해하고, 지난 콜과 무엇이 달라졌는지 확인하고, 내 포지션을 어떻게 할지 정하는 것입니다.

## 해결하려는 일

| ID | 상황 | 하고 싶은 일 | 기대 결과 |
|---|---|---|---|
| J1 | 관심 종목의 실적 발표가 다가올 때 | 언제 콜이 열리는지, 시장 기대치가 얼마인지 미리 알고 싶다 | 콜을 놓치지 않고 기준점을 갖고 들어간다 |
| J2 | 콜이 진행되는 동안 | 무슨 말이 나오는지 한국어로 이해하고, 지난 콜에서 한 말과 달라진 점을 바로 알고 싶다 | 영어·용어 장벽 없이 흐름을 따라간다 |
| J3 | 콜이 끝난 직후 | 전체를 종합한 판단과 근거를 보고 행동을 정하고 싶다 | 진입·관망·청산 중 하나를 근거와 함께 고른다 |
| J4 | 행동을 정했을 때 | 실수 없이 주문하고 결과를 확인하고 싶다 | 의도한 주문이 나가고 체결 여부를 안다 |
| J5 | 콜이 끝나고 시간이 지난 뒤 | 지난 콜의 판단과 내 거래를 되돌아보고 싶다 | 판단이 맞았는지, 내 대응이 어땠는지 안다 |
| J6 | 시연·평가 자리에서 | 짧은 시간에 기능 전체를 보여 주고 싶다 | 2~3분 안에 자막 → 직전 콜 대조 → 판단까지 보인다 |

J2 와 J3 이 제품의 중심입니다. J1 은 그 입구이고 J4·J5 는 보조입니다.

## 기능 범위

상태는 `main` 기준입니다. 계획은 이슈나 UX 재설계 결정에 잡혀 있고 아직 구현되지 않은 것입니다.

| 기능 | 해결하는 일 | 상태 |
|---|---|---|
| 어닝콜 자막 | J2 | 구현. [어닝콜 자막](features/live-transcript.md) |
| 직전 콜 대조 | J2 | 구현. 지난 콜 발언과 비교해 개선·후퇴·변화 없음 등으로 분류합니다([지난 분기 대비](features/fact-check.md#지난-분기-대비)) |
| 종합 판단(실행 판단, 질문 회피, 파급 영향, 손절·익절 계획) | J3 | 구현. [종합 판단](features/earnings-summary.md) |
| KIS 계좌 직접 주문(모의·실전) | J4 | 구현. [KIS 주문](features/trading.md) |
| 자체 페이퍼 계정 | J4 | 구현, 존속 미정. KIS 키 없이 앱 안에서 가상으로 체결합니다([UX 문서](design/ux.md#아직-정하지-않은-것)) |
| 실적 일정, 종목 정보, 시세 | J1 | 구현. [대시보드와 마켓](features/market.md) |
| 시연 재생 | J6 | 구현. 지난 어닝콜 녹취록을 서버가 재생합니다([ADR 0004](adr/0004-replay-past-earnings-call-for-demo.md)) |
| 자막 한국어 번역 | J2 | 계획 #110 |
| 용어 정의 보기 | J2 | 계획 #111 |
| 발언을 골라 질문하기 | J2 | 계획 #112 |
| 주문 접수 → 체결 반영 | J4 | 구현. 체결통보와 새로고침으로 반영합니다(#126, 장중 실검증 남음) |
| 콜 시작 알림 | J1 | 계획(2026-10-06 UX 재설계 결정) |
| 지난 콜 다시 보기 | J5 | 계획(2026-10-06 UX 재설계 결정). 서버의 결과 저장·조회가 먼저 필요합니다 |
| 시연 모드 분리 | J6 | 계획(2026-10-06 UX 재설계 결정). 시연을 일반 흐름과 나누고 시연 종목을 자동으로 고릅니다 |

시연은 실제 사용 흐름과 구분되는 모드입니다. 화면과 기능은 실제 사용을 기준으로 설계하고, 시연은 지난 콜을
재생해 같은 화면을 보여 주는 방식으로 다룹니다.

## 제외 범위

| 제외하는 것 | 이유 |
|---|---|
| 서버가 주문을 지시하는 기능 | 매매는 사용자가 직접 낸 주문만 지원합니다([ADR 0005](adr/0005-support-only-user-placed-orders.md)) |
| 실시간 뉴스 대조 팩트체크 | 2026-10-06 제외하기로 정했습니다. 발언 검증은 직전 콜 대조로 합니다. 현재 코드와 [실시간 팩트체크](features/fact-check.md) 문서, [ADR 0003](adr/0003-fact-check-with-evidence-retrieval-and-llm.md)에는 아직 남아 있으며, 기능을 제거할 때 함께 정리하고 ADR 0003 은 새 ADR 로 대체합니다 |
| 웹 버전 | 이 문서는 데스크톱 앱만 다룹니다. 저장소의 `frontend/` 는 존속 여부가 정해지지 않았습니다 |
