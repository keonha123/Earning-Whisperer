# 요구사항

EarningWhisperer Terminal 을 설치해 쓰는 데 필요한 운영체제, 네트워크, 계정 조건을 정리합니다.
설치 절차는 [데스크톱 앱 설치](desktop-app.md)에 있습니다.

## 운영체제

| 항목 | 조건 |
|---|---|
| OS | Windows x64 |
| 설치 권한 | 설치 마법사에서 범위를 고릅니다. 현재 사용자로 설치하면 관리자 권한이 필요 없습니다 |
| macOS | 배포 중인 설치 파일이 없습니다 |

현재 릴리스 `v0.1.0-rc1` 은 검증 중인 사전 릴리스입니다. 릴리스 노트에 따르면 Windows 에서 설치 후 실행을
확인하는 작업이 남아 있습니다(#115).

## 네트워크

| 대상 | 용도 |
|---|---|
| `https://api.logothea.com` | 시연 서버. 로그인, 시세, 어닝콜 재생, 팩트체크와 종합 판단 수신에 씁니다. 주소는 설치 파일에 포함되어 있어 따로 설정하지 않습니다 |
| 기본 웹 브라우저 | Google·카카오 로그인 창을 브라우저에서 엽니다 |
| PC 의 `localhost:9000` 포트 | 소셜 로그인 결과를 브라우저에서 앱으로 넘겨받을 때 잠깐 씁니다. 다른 프로그램이 이 포트를 쓰고 있으면 소셜 로그인이 실패합니다 |
| 한국투자증권 Open API | 주문, 잔고 조회, 보유·관심종목 현재가. 앱이 증권사 서버에 직접 접속합니다 |

시연 서버는 비용 때문에 필요할 때만 켜 둡니다. 켜져 있는지 확인하는 방법은 [FAQ](../overview/faq.md)에 있습니다.

## 계정

### EarningWhisperer 계정

Google 또는 카카오 계정으로 처음 로그인하면 계정이 자동으로 만들어집니다. 앱에는 이메일 회원가입 화면이
없으므로 이메일 로그인은 이미 가입된 계정에만 쓸 수 있습니다.

### KIS 모의투자 계좌와 API 키

첫 로그인 직후 `KIS API 키 등록` 화면에서 모의투자 또는 실전투자 중 한쪽 이상의 키를 등록해야 대시보드로
넘어갑니다. 등록에 필요한 값은 다음과 같습니다.

| 값 | 설명 |
|---|---|
| App Key, App Secret | 한국투자증권 KIS Developers 에서 발급받는 Open API 키 |
| 계좌번호 | 숫자 8자리(계좌번호) 또는 10자리(계좌 8자리 + 상품코드 2자리) |
| HTS ID (선택) | `설정` 화면에서 추가할 수 있습니다. 입력하면 체결 통보를 실시간으로 받습니다 |

키는 주문, 잔고, 체결 내역, 보유·관심종목 현재가 기능에서 씁니다. 어닝콜 재생과 팩트체크, 종합 판단은 KIS 를 거치지 않습니다.
주문 기능은 [KIS 주문](../features/trading.md)에서 설명합니다.
